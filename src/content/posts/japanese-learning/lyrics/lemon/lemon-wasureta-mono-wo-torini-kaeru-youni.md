# Lemon - 「忘れた物を取りに帰るように」

> <ruby>忘<rt>わす</rt></ruby>れた<ruby>物<rt>もの</rt></ruby>を<ruby>取<rt>と</rt></ruby>りに<ruby>帰<rt>かえ</rt></ruby>る<ruby>様<rt>よう</rt></ruby>に   <button class="pronunciation-play-btn" data-text="忘れた物を取りに帰るように">🔊 播放</button>
> 就像回去取忘記的東西一樣

## 📖 逐字分析

- **忘れた**（わすれた）：動詞「忘れる」的過去形，作定語修飾「物」
- **物**（もの）：名詞，東西、物品
- **を**：賓格助詞，表示動作的對象
- **取りに**（とりに）：動詞「取る」的連用形 + に，表示目的
- **帰る**（かえる）：動詞，回去、返回
- **ように**：助動詞「ようだ」的連用形，表示比喻或方式

## 🎯 文法結構解析

### 1. 忘れた（動詞過去形作定語）－修飾名詞

**文法功能**：動詞過去形直接修飾名詞，表示「已經...的」狀態。

**接續方式**：
- 動詞た形 + 名詞

**例句1**：<ruby>昨日<rt>きのう</rt></ruby><ruby>買<rt>か</rt></ruby>った<ruby>本<rt>ほん</rt></ruby>を<ruby>読<rt>よ</rt></ruby>む — 讀昨天買的書。

**例句2**：<ruby>先週<rt>せんしゅう</rt></ruby><ruby>会<rt>あ</rt></ruby>った<ruby>人<rt>ひと</rt></ruby>を<ruby>覚<rt>おぼ</rt></ruby>えている — 記得上週見過的人。

**歌曲應用**：<ruby>忘れた物<rt>わすれたもの</rt></ruby> — 忘記的東西（已經忘記的物品）

### 2. を取りに帰る（目的表達）－動作的目的

**文法功能**：使用「動詞連用形 + に + 動詞」表示「為了...而做...」的目的。

**接續方式**：
- 動詞ます形（去ます） + に + 動詞

**例句1**：<ruby>本<rt>ほん</rt></ruby>を<ruby>借<rt>か</rt></ruby>りに<ruby>図書館<rt>としょかん</rt></ruby>に<ruby>行<rt>い</rt></ruby>く — 去圖書館借書。

**例句2**：<ruby>食事<rt>しょくじ</rt></ruby>をしに<ruby>レストラン<rt>レストラン</rt></ruby>へ<ruby>行<rt>い</rt></ruby>った — 去餐廳吃飯。

**歌曲應用**：<ruby>取<rt>と</rt></ruby>りに<ruby>帰<rt>かえ</rt></ruby>る — 回去取（為了取回而回去）

### 3. ように（比喻表達）－表示「像...一樣」

**文法功能**：表示比喻、例示或動作的方式，相當於「像...一樣」「如同...」。

**接續方式**：
- 動詞辭書形/ない形 + ように
- い形容詞 + ように
- 名詞 + の + ように

**例句1**：<ruby>鳥のように空を飛びたい<rt>とりのようにそらをとびたい</rt></ruby> — 想像鳥一樣在天空飛翔。

**例句2**：<ruby>彼は子供のように笑った<rt>かれはこどものようにわらった</rt></ruby> — 他像小孩一樣笑了。

**歌曲應用**：<ruby>帰るように<rt>かえるように</rt></ruby> — 就像回去一樣（比喻某種行為或感覺）

## 🔄 完整句子結構分析

### 層次分解
1. **核心名詞**：忘れた物（忘記的東西）
2. **目的動作**：を取りに帰る（回去取）
3. **比喻表達**：ように（就像...一樣）

### 語法關係
- 「忘れた」修飾「物」，形成名詞片語
- 「を取りに帰る」描述對該名詞的動作
- 「ように」將整個動作比喻化，表達某種感覺或行為的相似性
