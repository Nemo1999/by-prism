# すずめ — 「それらが結ばれるのは 心の臓」

> それらが<ruby>結<rt>むす</rt></ruby>ばれるのは <ruby>心<rt>しん</rt></ruby>の<ruby>臓<rt>ぞう</rt></ruby> <button class="pronunciation-play-btn" data-text="それらが結ばれるのは心の臓">🔊 播放</button>
> 它們匯聚交錯的地方 正是心臟

## 📖 逐字分析

- **それら**<button class="pronunciation-play-btn" data-text="それら">🔊</button>：代名詞，那些（複數，指前一句的「赤と青き線」）
- **が**<button class="pronunciation-play-btn" data-text="が">🔊</button>：主格助詞
- **結ばれる**（むすばれる）<button class="pronunciation-play-btn" data-text="結ばれる">🔊</button>：動詞「結ぶ」的**受身形**（被動態），「被連結在一起」
- **の**：形式名詞 + 主題助詞，把前面的句子變成名詞子句（...這件事）
- **心の臓**（しんのぞう）<button class="pronunciation-play-btn" data-text="心の臓">🔊</button>：名詞，心臟（心的器官）

## 🎯 文法重點：受身形（被動態）

### 動詞受身形的規則

日文的受身形（〜れる／〜られる）表示「被...」、「受到...」的意思。

| 動詞類型 | 變化規則 | 範例 |
|---|---|---|
| **五段動詞** | ない形 + れる | 結ぶ → 結ば**ない** → 結ば**れる** |
| | | 書く → 書か**ない** → 書か**れる** |
| | | 読む → 読ま**ない** → 読ま**れる** |
| **一段動詞** | 辞書形 - る + られる | 食べる → 食べ**られる** |
| | | 見る → 見**られる** |
| **不規則** | 個別記憶 | する → **される**、来る → 来**られる**（こられる） |

### 結ぶ → 結ばれる 的完整變化過程

```
辞書形　　結ぶ（むすぶ）　　"連結"
  ↓
ない形　　結ばない　　　　　"不連結"（五段バ行：ぶ→ば）
  ↓
受身形　　結ばれる　　　　　"被連結"
```

### 歌詞中的意思

「それらが**結ばれる**」= 「那些（線）被連結在一起」→ 紅藍兩條線在心臟交會，隱喻生命與情感的匯聚。

## 📚 動詞變化規則：五段バ行動詞的活用

| 活用形 | 變化 | 結ぶ |
|---|---|---|
| 辞書形 | 〜ぶ | 結ぶ |
| ない形 | 〜ば + ない | 結ばない |
| て形 | 〜んで | 結んで |
| た形 | 〜んだ | 結んだ |
| 受身形 | 〜ば + れる | 結ばれる |
| 可能形 | 〜べる | 結べる |
| 意向形 | 〜ぼう | 結ぼう |
