# すずめ — 「時がたつほどに 増えてゆく」

> <ruby>時<rt>とき</rt></ruby>がたつほどに <ruby>増<rt>ふ</rt></ruby>えてゆく <button class="pronunciation-play-btn" data-text="時がたつほどに増えてゆく">🔊 播放</button>
> 隨著時間流逝 不斷增加

## 📖 逐字分析

- **時**（とき）<button class="pronunciation-play-btn" data-text="時">🔊</button>：名詞，時間、時光
- **が**<button class="pronunciation-play-btn" data-text="が">🔊</button>：主格助詞，標示主語
- **たつ**<button class="pronunciation-play-btn" data-text="たつ">🔊</button>：**五段動詞（タ行）**，表示「（時間）經過、流逝」。漢字可寫作「経つ」
- **ほどに**<button class="pronunciation-play-btn" data-text="ほどに">🔊</button>：副助詞「ほど」＋「に」，表示「隨著…的程度」。A ほどに B = 隨著 A 的變化，B 也跟著變化
- **増えて**（ふえて）<button class="pronunciation-play-btn" data-text="増えて">🔊</button>：**一段動詞**「増える」的て形，「增加、變多」
- **ゆく**<button class="pronunciation-play-btn" data-text="ゆく">🔊</button>：補助動詞「いく」的口語形/文語形。接在て形後面，表示變化**持續進行下去**

## 🎯 文法重點一：五段動詞「たつ」的活用

### 「たつ」的基本資訊

「たつ」（経つ）是五段タ行動詞，表示時間的經過。注意它跟「立つ」（站立）、「断つ」（切斷）同音但意思不同。

| 項目 | 內容 |
|---|---|
| **類型** | 五段動詞（タ行） |
| **辞書形** | たつ（経つ） |
| **意思** | （時間）經過、流逝 |
| **漢字** | 経つ（但在歌詞中通常不寫漢字以避免混淆） |

### 五段タ行動詞的變化規則

五段動詞的語尾在五個段上變化。タ行動詞以「つ」結尾，變化時「つ」變成「た・ち・つ・て・と」五個音：

| 活用形 | 變化 | たつ |
|---|---|---|
| 辞書形 | 〜つ | たつ |
| ない形 | 〜た + ない | た**た**ない |
| ます形 | 〜ち + ます | た**ち**ます |
| て形 | 〜って | た**って** |
| た形 | 〜った | た**った** |
| ば形 | 〜て + ば | た**て**ば |
| 意向形 | 〜と + う | た**と**う |

> ⚠️ 注意：五段動詞中，「う・つ・る」結尾的動詞，て形和た形都變成「って／った」。たつ → たって／たった。

### 更多「たつ」的例句

**例句1**：<ruby>時間<rt>じかん</rt></ruby>が**たつ**のが<ruby>早<rt>はや</rt></ruby>い — 時間過得很快。

**例句2**：<ruby>三<rt>さん</rt></ruby><ruby>年<rt>ねん</rt></ruby>が**たった** — 三年過去了。

## 🎯 文法重點二：比例變化「〜ほどに」

### 「ほどに」的用法

「ほど」是副助詞，表示程度。加上「に」之後變成「ほどに」，用來表示**比例變化**——A 變化，B 也隨之變化。

```
A（動詞辞書形）+ ほどに + B
＝ 隨著 A，B 也越來越…
```

| 句型 | 意思 |
|---|---|
| 時がたつ**ほどに**増える | 隨著時間經過而增加 |
| 年を取る**ほどに**体が弱くなる | 隨著年紀增長身體變弱 |
| 北へ行く**ほどに**寒くなる | 越往北走越冷 |

> 💡 「〜ほどに」和「〜ば〜ほど」（越…越…）意思相似，但「ほどに」更偏向書面語和歌詞，語氣較為詩意。

### 歌詞中的比例關係

「時がたつほどに 増えてゆく」= 時間流逝越多 → 某事物增加越多

這裡暗指隨著時間過去，某些東西（可能是回憶、傷痕、或是門後的災厄）不會減少，反而**越來越多**。這與電影中「關上災厄之門」的主題形成對比。

## 🎯 文法重點三：持續變化「〜てゆく」

### 「〜てゆく」vs「〜ていく」

「ゆく」是「いく」的口語形/文語形，兩者意思完全相同：

| 形式 | 語氣 | 使用場合 |
|---|---|---|
| 〜ていく | 標準口語 | 日常對話 |
| 〜てゆく | 稍文雅/詩意 | 歌詞、文學、正式場合 |

「〜ていく／〜てゆく」接在て形後面，表示**變化持續進行下去**：

| 意思 | 例句 |
|---|---|
| 空間上的遠去 | <ruby>鳥<rt>とり</rt></ruby>が<ruby>飛<rt>と</rt></ruby>んでいく — 鳥飛走了 |
| 時間上的持續 | これからも<ruby>生<rt>い</rt></ruby>きてゆく — 今後也要活下去 |
| 變化持續進行 | <ruby>星<rt>ほし</rt></ruby>が<ruby>消<rt>き</rt></ruby>えてゆく — 星星逐漸消失 |

與「〜てくる」（變化從過去到現在）相對，「〜ていく」是變化**從現在到未來**。

### 「増える」的て形變化

「増える」（ふえる）是**一段動詞**：

```
辞書形　　増える（ふえる）
  ↓  去掉「る」
語幹　　　増え
  ↓  + て
て形　　　増えて
```

「増えてゆく」= 不斷增加下去（持續到未來）。

### 更多「〜てゆく」例句

**例句3**：<ruby>思<rt>おも</rt></ruby>い<ruby>出<rt>で</rt></ruby>が**増えてゆく** — 回憶不斷增加。
<button class="pronunciation-play-btn" data-text="思い出が増えてゆく">🔊 朗讀</button>

**例句4**：<ruby>少<rt>すこ</rt></ruby>しずつ<ruby>変<rt>か</rt></ruby>わってゆく<ruby>景色<rt>けしき</rt></ruby> — 逐漸改變的景色。
<button class="pronunciation-play-btn" data-text="少しずつ変わってゆく景色">🔊 朗讀</button>

> 🎵 歌詞意境：時間只會一直向前，隨著時間累積的東西也越來越多——無論是回憶、情感還是未關上的門。這句承接前一句「開け放しのドア 閉じたはずの部屋」：本該關上的門不但沒關，反而隨著時間越來越多。

## 📚 動詞變化規則：五段タ行動詞 vs 一段動詞

| | 五段タ行動詞 | 一段動詞 |
|---|---|---|
| **範例** | たつ（経つ） | 増える（ふえる） |
| **辞書形** | たつ | 増える |
| **ない形** | たたない | 増えない |
| **ます形** | たちます | 増えます |
| **て形** | たって | 増えて |
| **た形** | たった | 増えた |
| **ば形** | たてば | 増えれば |
| **意向形** | たとう | 増えよう |

> ⚠️ 五段動詞和一段動詞的て形是天壤之別：五段動詞要看語尾來變化，一段動詞一律去る+て。這也是為什麼初學者需要特別練習五段動詞的て形！
