## 📖 逐字分析

- **君**（きみ）<button class="pronunciation-play-btn" data-text="君">🔊</button>：代名詞，你（較親密的稱呼）
- **の中に**（のなかに）<button class="pronunciation-play-btn" data-text="中に">🔊</button>：在...之中。**に** 表示存在的位置
- **ある**<button class="pronunciation-play-btn" data-text="ある">🔊</button>：動詞，存在、有（無意志物體的存在）
- **赤**（あか）<button class="pronunciation-play-btn" data-text="赤">🔊</button>：名詞，紅色

## 🎯 文法重點：存在動詞「ある」

### ある 的基本資訊

| 項目 | 內容 |
|---|---|
| 類型 | 五段動詞（ラ行） |
| 意思 | 有、存在（**無意志**物體） |
| 對應 | いる（有意志的人和動物） |

### ある vs いる

| | ある | いる |
|---|---|---|
| 對象 | 物、植物、抽象概念 | 人、動物 |
| 例句 | 机の上に本が**ある** — 桌上有書 | 教室に学生が**いる** — 教室裡有學生 |
| 例句 | 君の中に線が**ある** — 你體內有線（歌詞） | 君がここに**いる** — 你在這裡 |

### ある 的變化形（五段ラ行動詞）

| 活用形 | 變化 | 例句 |
|---|---|---|
| **辞書形** | ある | <ruby>本<rt>ほん</rt></ruby>が**ある** — 有書 |
| **ない形** | ない | <ruby>何<rt>なに</rt></ruby>も**ない** — 什麼都沒有 |
| **て形** | あって | <ruby>理由<rt>りゆう</rt></ruby>が**あって** — 有理由（而...） |
| **た形** | あった | <ruby>昔<rt>むかし</rt></ruby>、<ruby>物語<rt>ものがたり</rt></ruby>が**あった** — 從前，有個故事 |
| **ば形** | あれば | <ruby>時間<rt>じかん</rt></ruby>が**あれば** — 如果有時間 |

## 📚 動詞變化規則：五段動詞

日文動詞分為三大類，**五段動詞**是數量最多的一類：

### 如何辨識五段動詞？

辭書形（原形）結尾不是「〜る」，**或者**雖然是「〜る」但る前面的音不在「い段」或「え段」：

| 範例 | 辨識 |
|---|---|
| 書く（かく） | ✅ く結尾 → 五段 |
| 読む（よむ） | ✅ む結尾 → 五段 |
| ある | ✅ る前是「あ段」→ 五段 |
| 走る（はしる） | ✅ る前是「い段」但屬例外 → 五段 |
| 食べる（たべる） | ❌ る前是「え段」→ **一段動詞** |

### 五段動詞的て形/た形變化

五段動詞的て形和た形，依照**辭書形最後一個音**變化：

| 結尾 | て形 | た形 | 範例 |
|---|---|---|---|
| く | いて | いた | 書く → 書**いて** / 書**いた** |
| ぐ | いで | いだ | 泳ぐ → 泳**いで** / 泳**いだ** |
| う・つ・る | って | った | 待つ → 待**って** / 待**った**、ある → あ**って** / あ**った** |
| ぬ・ぶ・む | んで | んだ | 読む → 読**んで** / 読**んだ** |
| す | して | した | 話す → 話**して** / 話**した** |

> 「ある」是ラ行動詞，遵循「う・つ・る」組的規則：あ**って** / あ**った**
