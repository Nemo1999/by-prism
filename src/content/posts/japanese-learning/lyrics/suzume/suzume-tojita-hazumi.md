> <ruby>開<rt>あ</rt></ruby>け<ruby>放<rt>ぱな</rt></ruby>しのドア <ruby>閉<rt>と</rt></ruby>じたはずの<ruby>部屋<rt>へや</rt></ruby> <button class="pronunciation-play-btn" data-text="開け放しのドア閉じたはずの部屋">🔊 播放</button>
> 敞開著的門 本該已關上的房間

## 📖 逐字分析

- **開け放し**（あけぱなし）<button class="pronunciation-play-btn" data-text="開け放し">🔊</button>：名詞，「開けっ放し」的口語形。一直開著的狀態
- **ドア**<button class="pronunciation-play-btn" data-text="ドア">🔊</button>：門（door）
- **閉じた**（とじた）<button class="pronunciation-play-btn" data-text="閉じた">🔊</button>：動詞「閉じる」的**た形**（過去/完了），「關上了」
- **はず**<button class="pronunciation-play-btn" data-text="はず">🔊</button>：形式名詞，表示「應該、理應」
- **部屋**（へや）<button class="pronunciation-play-btn" data-text="部屋">🔊</button>：名詞，房間

## 🎯 文法重點：一段動詞 vs 五段動詞

### 為什麼「閉じた」是一段動詞？

日文有兩個表示「關」的常用動詞：

| | 閉じる（とじる） | 閉める（しめる） |
|---|---|---|
| **類型** | 一段動詞 | 五段動詞 |
| **辭書形** | 閉じる | 閉める |
| **辨識** | る前是「じ」= い段音 | る前是「め」= え段音，但しめる是五段 |
| **意思** | 關上（書、門、眼睛等） | 關上（門、窗等） |
| **た形** | 閉**じた** | 閉**めた** |
| **て形** | 閉**じて** | 閉**めて** |
| **ない形** | 閉**じない** | 閉**めない** |

> 💡 「る」前面的音在「い段」或「え段」→ **通常**是一段動詞。但有例外（如「入る・はいる」是五段、「走る・はしる」也是五段）。

### 一段動詞的變化規則

一段動詞的變化**非常簡單**：去掉「る」，直接加上後面的活用語尾。

| 活用形 | 變化 | 閉じる |
|---|---|---|
| 辞書形 | 〜る | 閉じる |
| ない形 | 〜ない | 閉じない |
| て形 | 〜て | 閉じて |
| た形 | 〜た | 閉じた |
| ば形 | 〜れば | 閉じれば |
| 受身形 | 〜られる | 閉じられる |
| 可能形 | 同受身形 | 閉じられる |
| 意向形 | 〜よう | 閉じよう |

### 歌詞中的語法

「閉じたはずの部屋」= 應該已經關上了的房間

- **閉じた** = 關上了（た形，表示完了/過去）
- **はず** = 應該、理應（基於常識或已知事實的推測）

這句話有個反差：門是「開け放し」（一直開著），但「應該已經關上了」— 暗示某種異常或未完成的事情。

## 📚 五段動詞 vs 一段動詞：快速辨識表

| 判斷方法 | 五段動詞 | 一段動詞 |
|---|---|---|
| 辭書形非る結尾 | ✅ 必是五段 | — |
| る前是あ段 | ある ✅ | — |
| る前是う段 | 作る（つくる）✅ | — |
| る前是お段 | 取る（とる）✅ | — |
| る前是い段 | 走る（はしる）⚠️例外 | 起きる（おきる）✅ |
| る前是え段 | 帰る（かえる）⚠️例外 | 食べる（たべる）✅ |

> ⚠️ い段・え段 + る 的動詞需要**個別記憶**，沒有萬能規則。但大多數是一段動詞。
