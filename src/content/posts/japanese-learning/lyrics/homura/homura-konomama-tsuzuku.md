# 炎 — 「このまま続くと思っていた」

> このまま<ruby>続<rt>つづ</rt></ruby>くと思<rt>おも</rt>っていた <button class="pronunciation-play-btn" data-text="このまま続くと思っていた">🔊 播放</button>
> 我曾以為會就這樣一直持續下去

這句歌詞是《炎》前半段非常重要的一句話。這首歌是《<ruby>鬼滅<rt>きめつ</rt></ruby>の<ruby>刃<rt>やいば</rt></ruby> 無限<ruby>列車<rt>れっしゃ</rt></ruby>編》的主題曲，寫的是與重要之人離別的悲傷。唱到這裡時，主角回想起過去那些平凡卻溫暖的日子——當時天真的以為「這樣的日子會一直持續下去」，但現實卻不是如此。短短一句話，就藏著深深的失落感。

先看看這句歌詞的結構：

```
このまま 続く と 思っていた
（就這樣）（持續）（引用）（一直以為）
＝ 我曾以為會就這樣一直持續下去
```

整句話的意思是：「我（當時）一直以為，這樣的日子會就這樣一直持續下去。」下面我們一個一個詞來拆解。

## 📖 逐字分析

- **このまま**（このまま）<button class="pronunciation-play-btn" data-text="このまま">🔊</button>：副詞，就這樣、維持現狀。「この」＋「まま」組成；「まま」表示「保持某種狀態、不改變」。歌詞中「このまま<ruby>続<rt>つづ</rt></ruby>く」就是「就這樣一直持續下去」。
- **続く**（<ruby>続<rt>つづ</rt></ruby>く）<button class="pronunciation-play-btn" data-text="続く">🔊</button>：動詞（五段動詞），持續、繼續。讀音是「つづく」，不是「ぞく」喔（<ruby>続<rt>ぞく</rt></ruby>是音讀，出現在<ruby>継続<rt>けいぞく</rt></ruby>（繼續）這類漢語詞裡）。這裡用辭書形直接接「と」。
- **と**（と）<button class="pronunciation-play-btn" data-text="と">🔊</button>：引用助詞，把前面的內容「このまま続く」整個框起來，當作後面「思っていた」的想法內容。中文通常不直接翻譯，或翻成「（以為）會…」。
- **思っていた**（<ruby>思<rt>おも</rt></ruby>っていた）<button class="pronunciation-play-btn" data-text="思っていた">🔊</button>：動詞「<ruby>思<rt>おも</rt></ruby>う」（想、認為）的て形＋「いた」（＝「いる」的過去形），表示「過去一直認為、一直以為」。重點：用過去形，暗示「現在已經不這麼想了」。

小提醒：**詞性**就是單字的「身分證」，告訴我們這個字是名詞、動詞還是副詞；**五段動詞**是日文動詞的一種變化類型（還有上一段、下一段等），<ruby>続<rt>つづ</rt></ruby>く和<ruby>思<rt>おも</rt></ruby>う都屬於五段動詞。把四個詞的資訊整理成表格：

| 語 | 讀音 | 詞性 | 意思 |
| --- | --- | --- | --- |
| このまま | このまま | 副詞 | 就這樣、維持現狀 |
| <ruby>続<rt>つづ</rt></ruby>く | つづく | 五段動詞 | 持續、繼續 |
| と | と | 引用助詞 | （引用前面的內容） |
| <ruby>思<rt>おも</rt></ruby>っていた | おもっていた | 動詞て形＋いた | 一直以為、當時認為 |

## 🎯 文法重點：「このまま」與「〜と思っていた」

### 1. 「このまま」— 維持現狀、不改變

「このまま」由「この」（這個）＋「まま」組成。「まま」是一個很特別的字，表示「保持原本的狀態、照原樣」。所以「このまま」就是「維持現在這個樣子、什麼都不改變」。

| 語 | 意思 | 用法 |
| --- | --- | --- |
| このまま | 就這樣（維持現在這個狀態） | 指「現在」的狀態不改變 |
| そのまま | 就那樣（維持那個狀態） | 指「對方或遠處」的狀態不改變 |

歌詞裡「このまま<ruby>続<rt>つづ</rt></ruby>く」＝「維持現在的樣子繼續下去」，有一種「希望時間停在這裡」的感覺。

**例句1**：このまま<ruby>帰<rt>かえ</rt></ruby>りたい <button class="pronunciation-play-btn" data-text="このまま帰りたい">🔊</button>
— 我想就這樣回家。（不想改變現狀，直接回家）

**例句2**：このまま<ruby>待<rt>ま</rt></ruby>っていてください <button class="pronunciation-play-btn" data-text="このまま待っていてください">🔊</button>
— 請就這樣等著。（保持現在的位置／狀態不要動）

**歌詞應用**：這裡的「このまま」＋「<ruby>続<rt>つづ</rt></ruby>く」＝「就這樣繼續下去」。主角希望現在平凡溫暖的日子可以永遠不變——但接下來的事實卻不是如此，這就帶出了整句歌詞的遺憾。

### 2. 〜と思っていた vs 〜と思う — 「一直以為」與「覺得」

「<ruby>思<rt>おも</rt></ruby>う」是「想、認為」的意思。但用什麼「時態」來想，語氣差很多：

| 形 | 構成 | 意思 | 語氣 |
| --- | --- | --- | --- |
| と思う | 思う（現在形） | 覺得、認為 | 現在的判斷，客觀敘述 |
| と思っている | 思う＋ている | 一直覺得 | 現在仍然抱持這個想法 |
| と思っていた | 思う＋ていた | 一直以為 | 過去持續的想法，暗示現在已經不這麼想了 |

重點就在最後一個：**「〜と思っていた」是過去的持續想法**。用過去形，就代表那個想法「已經結束了」——要嘛想法變了，要嘛被現實打破了。所以「〜と思っていた」常常帶有失落、懷念、遺憾的語氣。

**例句3**：ずっと<ruby>一<rt>いっ</rt></ruby><ruby>緒<rt>しょ</rt></ruby>にいられると思っていた <button class="pronunciation-play-btn" data-text="ずっと一緒にいられると思っていた">🔊</button>
— 我以為能一直在一起。（但現在分開了）

**例句4**：<ruby>雨<rt>あめ</rt></ruby>は<ruby>上<rt>あ</rt></ruby>がらないと思っていた <button class="pronunciation-play-btn" data-text="雨は上がらないと思っていた">🔊</button>
— 我以為雨不會停。（結果後來雨停了，或一直下到讓人意外）

**例句5**：<ruby>大丈夫<rt>だいじょうぶ</rt></ruby>だと思っていた <button class="pronunciation-play-btn" data-text="大丈夫だと思っていた">🔊</button>
— 我以為沒問題。（結果出了問題，帶有懊悔）

**例句6**（模仿歌詞）：このまま<ruby>毎日<rt>まいにち</rt></ruby>が<ruby>続<rt>つづ</rt></ruby>くと思っていた <button class="pronunciation-play-btn" data-text="このまま毎日が続くと思っていた">🔊</button>
— 我以為這樣的日子會一直持續下去。

把「現在」和「過去」放在一起看，差別更清楚：

**例句7**：<ruby>大丈夫<rt>だいじょうぶ</rt></ruby>だと思う <button class="pronunciation-play-btn" data-text="大丈夫だと思う">🔊</button>
— 我覺得沒問題。（現在的判斷）

**例句8**：<ruby>大丈夫<rt>だいじょうぶ</rt></ruby>だと思っていた <button class="pronunciation-play-btn" data-text="大丈夫だと思っていた">🔊</button>
— 我（以前）以為沒問題。（暗示後來出事了）

同樣是「<ruby>大丈夫<rt>だいじょうぶ</rt></ruby>だ」，「と思う」只是在描述現在的想法，聽起來很中性；一旦換成「と思っていた」，聽的人就會知道「這個想法已經結束了」，背後往往藏著一句沒說出口的「但是……」。

**歌詞應用**：這句歌詞用的正是「〜と思っていた」——「<ruby>思<rt>おも</rt></ruby>っていた」是過去持續的想法。主角「曾經一直以為」這樣的日子會永遠持續，但那個「以為」已經被現實打破，所以現在回想起來，只剩下失落與不捨。如果改成「〜と思う」（現在形），就變成「我（現在）覺得會持續下去」，完全沒有這種「美好的日常被突然打破」的感傷了。用「思っていた」三個字，就悄悄說明了：那樣的日子，已經回不去了。

### 3. 小補充：動詞て形＋いた（過去的持續狀態）

「〜ていた」是「〜ている」的過去形。「〜ている」表示動作或狀態「正在持續」，例如「<ruby>食<rt>た</rt></ruby>べている」（正在吃）；「〜ていた」則是把時間拉到過去，例如「<ruby>食<rt>た</rt></ruby>べていた」（（那時候）正在吃）。<ruby>思<rt>おも</rt></ruby>う＋て＋いた＝<ruby>思<rt>おも</rt></ruby>っていた，就是「（過去那段時間）一直這麼想」。

變化過程：

```
思う（辭書形）→ 思って（て形）→ 思っていた（て形＋いた）
```

て形怎麼變化，屬於**動詞變化**的基礎規則。想複習的話，可以看文末的相關文法連結喔。

### まとめ（重點整理）

1. **このまま**＝「維持現狀、什麼都不改變」；「このまま<ruby>続<rt>つづ</rt></ruby>く」＝「就這樣一直持續下去」。
2. **〜と思っていた**＝「（過去）一直以為…」，用過去形暗示「現在已經不這麼想了」，帶有失落與遺憾。
3. 對比：**〜と思う**（現在的判斷）vs **〜と思っていた**（過去持續、已被打破的想法）。
4. **〜ていた**＝「〜ている」的過去形，表示過去的持續狀態。

下次唱到「このまま<ruby>続<rt>つづ</rt></ruby>くと思<rt>おも</rt>っていた」時，可以想想：歌詞用「思っていた」而不是「思う」，就是為了告訴我們——那些以為會永遠持續的日常，已經在不知不覺中結束了。
