# 炎 — 「前だけ向いて叫ぶから」

> <ruby>前<rt>まえ</rt></ruby>だけ<ruby>向<rt>む</rt></ruby>いて<ruby>叫<rt>さけ</rt></ruby>ぶから <button class="pronunciation-play-btn" data-text="前だけ向いて叫ぶから">🔊 播放</button>
> 因為我只會面向前方吶喊

這一句是《炎》結尾的高潮之一。上一句是「<ruby>振<rt>ふ</rt></ruby>り返らずに<ruby>進<rt>すす</rt></ruby>むから」（因為我會不回頭地前進），這一句接著說「因為我只會面向前方吶喊」。

兩句都用「〜から」收尾，形成漂亮的對稱：一個說「不回頭」，一個說「只向前」；一個說「前進」，一個說「吶喊」。合起來，就是把主角「不回頭、只向前、大聲喊出心意」的決心，一口氣推到最高點。

這一頁我們要學兩個很重要的文法：限定助詞「だけ」（只）和理由助詞「から」（因為）。兩個都很簡單，學會之後，你就能看懂好多日文歌詞！

## 📖 逐字分析

- **<ruby>前<rt>まえ</rt></ruby>**（まえ）<button class="pronunciation-play-btn" data-text="前">🔊</button>：名詞，「前方、前面」。這裡指「前方」，和上一句的「<ruby>振<rt>ふ</rt></ruby>り返らずに」（不回頭）互相呼應——不看後面，只看前面。
- **だけ**（だけ）<button class="pronunciation-play-btn" data-text="だけ">🔊</button>：限定助詞，「只、僅」。接在名詞後面，表示「只有這個範圍，其他都不要」。等一下在文法重點會詳細講。
- **<ruby>向<rt>む</rt></ruby>いて**（むいて）<button class="pronunciation-play-btn" data-text="向いて">🔊</button>：動詞「<ruby>向<rt>む</rt></ruby>く」（朝向、面對）的て形。五段動詞的「く」變成「いて」，這是日文的「音便」規則。て形在這裡表示「以『面向～』的狀態」去做下一個動作。
- **<ruby>叫<rt>さけ</rt></ruby>ぶ**（さけぶ）<button class="pronunciation-play-btn" data-text="叫ぶ">🔊</button>：動詞（五段動詞），「吶喊、大叫」。把心裡的話大聲喊出來，比「<ruby>言<rt>い</rt></ruby>う」（說）更有感情、更有力量。
- **から**（から）<button class="pronunciation-play-btn" data-text="から">🔊</button>：理由助詞，「因為」。放在句尾，表示「前面整句話是理由」。

把整句拆開來看：

<ruby>前<rt>まえ</rt></ruby>だけ（只有前方）＋<ruby>向<rt>む</rt></ruby>いて（面向著）＋<ruby>叫<rt>さけ</rt></ruby>ぶ（吶喊）＋から（因為）

＝「因為（我）只會面向前方吶喊」。

小提醒：這裡的「<ruby>向<rt>む</rt></ruby>いて」不是「請你面向前方」的命令，而是「以『面向前方』的狀態」去吶喊。て形可以表示動作連續或狀態伴隨，例如「<ruby>走<rt>はし</rt></ruby>って<ruby>叫<rt>さけ</rt></ruby>ぶ」（邊跑邊喊）也是一樣的用法。

## 🎯 文法重點：〜だけ 與 〜から

### 1. 「〜だけ」：限定「只」

「だけ」是限定助詞，接在名詞（或數量詞）後面，表示「只有這個範圍，其他都不要」。對初學者來說，可以簡單記成中文的「只」。

句型：

```
<名詞／數量詞> ＋ だけ
```

例如：<ruby>前<rt>まえ</rt></ruby>だけ ＝ 只有前方；<ruby>少<rt>すこ</rt></ruby>しだけ ＝ 只有一點點。

**例句1**：<ruby>前<rt>まえ</rt></ruby>だけ<ruby>見<rt>み</rt></ruby>る <button class="pronunciation-play-btn" data-text="前だけ見る">🔊</button>
— 只看著前方（不看別的地方）

**例句2**：<ruby>少<rt>すこ</rt></ruby>しだけ<ruby>食<rt>た</rt></ruby>べる <button class="pronunciation-play-btn" data-text="少しだけ食べる">🔊</button>
— 只吃一點點（不多吃）

**例句3**：<ruby>水<rt>みず</rt></ruby>だけ<ruby>飲<rt>の</rt></ruby>む <button class="pronunciation-play-btn" data-text="水だけ飲む">🔊</button>
— 只喝水（不喝果汁、不喝別的）

**歌詞應用**：<ruby>前<rt>まえ</rt></ruby>だけ<ruby>向<rt>む</rt></ruby>いて<ruby>叫<rt>さけ</rt></ruby>ぶから —— 「<ruby>前<rt>まえ</rt></ruby>＋だけ」＝「只有前方」。不看左右、不看後面，眼光只鎖定前方。這就是「だけ」把範圍縮到最小的力量，也表現出主角毫不猶豫的決心。

### 2. 「〜から」：理由「因為」

「から」是理由助詞，接在句子（普通形）後面，表示「因為～」。日文的語順是「理由 から ＋ 結果」，跟中文「因為～所以～」很像，只是「から」要放在理由句的句尾。

句型：

```
<理由句（普通形）> ＋ から ＋ <結果>
```

例如：<ruby>信<rt>しん</rt></ruby>じるから（因為相信）＋<ruby>強<rt>つよ</rt></ruby>くなれる（能變強）＝因為相信，所以能變強。

**例句1**：<ruby>信<rt>しん</rt></ruby>じるから<ruby>強<rt>つよ</rt></ruby>くなれる <button class="pronunciation-play-btn" data-text="信じるから強くなれる">🔊</button>
— 因為相信，所以能變強

**例句2**：<ruby>疲<rt>つか</rt></ruby>れたから<ruby>休<rt>やす</rt></ruby>む <button class="pronunciation-play-btn" data-text="疲れたから休む">🔊</button>
— 因為累了，所以休息

**例句3**：<ruby>好<rt>す</rt></ruby>きだから<ruby>頑張<rt>がんば</rt></ruby>れる <button class="pronunciation-play-btn" data-text="好きだから頑張れる">🔊</button>
— 因為喜歡，所以能努力

**歌詞應用**：<ruby>前<rt>まえ</rt></ruby>だけ<ruby>向<rt>む</rt></ruby>いて<ruby>叫<rt>さけ</rt></ruby>ぶから —— 句尾的「から」說明「我會這樣做」的理由：因為我只會面向前方吶喊。和上一句「<ruby>振<rt>ふ</rt></ruby>り返らずに<ruby>進<rt>すす</rt></ruby>むから」同樣用「から」收尾，兩句並排，像互相呼應的決心宣言。

**補充：て形連接**：<ruby>空<rt>そら</rt></ruby>に<ruby>向<rt>む</rt></ruby>いて<ruby>叫<rt>さけ</rt></ruby>ぶ <button class="pronunciation-play-btn" data-text="空に向いて叫ぶ">🔊</button>
— 對著天空吶喊。這句和歌詞用了一模一樣的結構：「<ruby>向<rt>む</rt></ruby>いて」把「朝向」和「吶喊」連起來，意思是「以面向～的姿勢吶喊」。注意「<ruby>向<rt>む</rt></ruby>く」的對象要用助詞「に」，所以是「<ruby>空<rt>そら</rt></ruby>に<ruby>向<rt>む</rt></ruby>いて」。

### 歌詞小教室：與上一句的對稱

把兩句放在一起看：

上一句：<ruby>振<rt>ふ</rt></ruby>り返らずに<ruby>進<rt>すす</rt></ruby>むから <button class="pronunciation-play-btn" data-text="振り返らずに進むから">🔊</button>（因為我會不回頭地前進）
這一句：<ruby>前<rt>まえ</rt></ruby>だけ<ruby>向<rt>む</rt></ruby>いて<ruby>叫<rt>さけ</rt></ruby>ぶから <button class="pronunciation-play-btn" data-text="前だけ向いて叫ぶから">🔊</button>（因為我只會面向前方吶喊）

對稱點有三個：

- 兩句都以「〜から」收尾，都是「理由」——先說原因，再說決心。
- 「<ruby>振<rt>ふ</rt></ruby>り返らずに」（不回頭）vs「<ruby>前<rt>まえ</rt></ruby>だけ」（只向前）——一個用否定，一個用限定，但都在講同一件事：向前看。
- 「<ruby>進<rt>すす</rt></ruby>む」（前進）vs「<ruby>叫<rt>さけ</rt></ruby>ぶ」（吶喊）——行動上互相補充：不只是往前走，還要大聲喊出來。

所以這兩句合起來，就是整首歌最強烈的訊息：不回頭、只向前，把心裡的話大聲喊出來。

## 📝 重點整理

把這一頁學到的東西整理成表格，方便複習：

| 項目 | 用法 | 意思 | 歌詞中的例子 |
| --- | --- | --- | --- |
| だけ | 名詞＋だけ | 只、僅 | <ruby>前<rt>まえ</rt></ruby>だけ（只有前方） |
| から | 理由句（普通形）＋から | 因為 | <ruby>叫<rt>さけ</rt></ruby>ぶから（因為吶喊） |
| <ruby>向<rt>む</rt></ruby>く | 五段動詞，く→いて | 朝向、面對 | <ruby>向<rt>む</rt></ruby>いて（面向著） |
| <ruby>叫<rt>さけ</rt></ruby>ぶ | 五段動詞 | 吶喊、大叫 | <ruby>叫<rt>さけ</rt></ruby>ぶ（吶喊） |

單字小複習：

- <ruby>前<rt>まえ</rt></ruby>（まえ）：前方。和「<ruby>後<rt>うし</rt></ruby>ろ」（後面）是相反詞。
- <ruby>空<rt>そら</rt></ruby>（そら）：天空。歌詞裡「<ruby>空<rt>そら</rt></ruby>に<ruby>向<rt>む</rt></ruby>いて<ruby>叫<rt>さけ</rt></ruby>ぶ」就是「對著天空吶喊」。
- <ruby>強<rt>つよ</rt></ruby>くなる（つよくなる）：變強。「<ruby>強<rt>つよ</rt></ruby>い」（強的）＋「なる」（變成）的組合。

下次聽到「<ruby>前<rt>まえ</rt></ruby>だけ<ruby>向<rt>む</rt></ruby>いて<ruby>叫<rt>さけ</rt></ruby>ぶから」的時候，記得這是主角的決心宣言：不回頭、只向前、大聲喊出來！
