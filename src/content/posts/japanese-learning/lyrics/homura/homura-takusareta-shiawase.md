# 炎 — 「託された幸せと 約束を超えて行く」

> <ruby>託<rt>たく</rt></ruby>された<ruby>幸<rt>しあわ</rt></ruby>せと <ruby>約束<rt>やくそく</rt></ruby>を<ruby>超<rt>こ</rt></ruby>えて<ruby>行<rt>い</rt></ruby>く <button class="pronunciation-play-btn" data-text="託された幸せと 約束を超えて行く">🔊 播放</button>
> 超越被託付的幸福與約定，繼續前行

這句歌詞出自 LiSA 的《炎》（動畫《鬼滅の刃》無限列車篇主題曲），是整首歌情緒翻轉的關鍵一句。在它前面，歌詞唱的是「<ruby>輝<rt>かがや</rt></ruby>いて<ruby>消<rt>き</rt></ruby>えてった <ruby>未来<rt>みらい</rt></ruby>のために」（為了那閃耀後消逝的未來）——那道光芒（炎柱・煉獄杏壽郎）已經消逝了。但接下來這句沒有繼續沉浸在悲傷裡，而是說：**被託付的幸福與約定，我們會超越它、繼續前行**。

對看過《無限列車篇》的人來說，這句的畫面再清楚不過：煉獄さん在黎明前倒下之前，把一切都託付給了炭治郎他們——「<ruby>心<rt>こころ</rt></ruby>を<ruby>燃<rt>も</rt></ruby>やせ」（讓心燃燒吧）。留下來的人不是兩手空空地悲傷，而是背負著那份託付，繼續往前走。這就是「託された幸せと 約束を超えて行く」的意思。

這句歌詞同時藏了兩個重要的日文文法：**受身形（被動）**「託される」和**補助動詞**「〜て行く」。兩個都是初學者一定要認識的基礎，我們一起來拆解！

## 📖 逐字分析

下面的「逐字分析」會用到幾個簡單的文法用語（詞性）：**名詞**＝表示人、事、物、概念名稱的詞（如：幸福、約定）；**助詞**＝本身沒有意思、用來連接單字或標示關係的小詞（如：と、を）；**動詞**＝表示動作或狀態的詞（如：託す、超える）；**受身形（受身）**＝動詞表示「被～」的形狀（如：託す→託される）；**て形**＝動詞的「連接形」，用來把動作接續下去（如：超える 的て形是 超えて）；**補助動詞**＝失去原本意思、只負責補充語感的動詞（如：て形後面的 行く）。先記住這幾個，接下來就看得懂了。

- **<ruby>託<rt>たく</rt></ruby>された**（たくされた）<button class="pronunciation-play-btn" data-text="託された">🔊</button>：動詞 <ruby>託<rt>たく</rt></ruby>す（たくす，託付、寄託）的**受身形**「託される」＋**た形**（過去），意思為「被託付了」。這是本句第一個文法重點，下面會詳細說明！
- **<ruby>幸<rt>しあわ</rt></ruby>せ**（しあわせ）<button class="pronunciation-play-btn" data-text="幸せ">🔊</button>：名詞，「幸福、幸運」。讀音要注意：漢字只有「幸」一個字，讀成「しあわ」，後面再接平假名「せ」，合起來才是「しあわせ」。
- **と**<button class="pronunciation-play-btn" data-text="と">🔊</button>：**並列助詞**，意思為「和、與」，用來把兩個名詞並排在一起。這裡的「幸せと 約束」＝「幸福與約定」。日文的 と 還有很多其他用法（例如表示「引用」的 と），這裡是並列用法。
- **<ruby>約束<rt>やくそく</rt></ruby>**（やくそく）<button class="pronunciation-play-btn" data-text="約束">🔊</button>：名詞，「約定、承諾」。詳細可參考[[posts/japanese-learning/vocabulary/yakusoku|約束（やくそく）]]。
- **を**<button class="pronunciation-play-btn" data-text="を">🔊</button>：**對象助詞**，標示動作的對象。這裡的「約束を超えて」＝「超越約定」，を 的後面接的是動詞 超える。
- **<ruby>超<rt>こ</rt></ruby>えて**（こえて）<button class="pronunciation-play-btn" data-text="超えて">🔊</button>：動詞 <ruby>超<rt>こ</rt></ruby>える（こえる，超越、越過）的て形。て形把動作「暫停」在這裡，表示「超越…，然後…」，和後面的「行く」接成一個連續的動作。
- **<ruby>行<rt>い</rt></ruby>く**（いく）<button class="pronunciation-play-btn" data-text="行く">🔊</button>：**補助動詞**，接在動詞て形後面（〜て行く），表示「持續進行、往未來延伸」的語感。這裡不是真的「走路」的意思，而是「就這樣繼續走下去」。這是本句第二個文法重點！

把整句拆開直譯就是：「（我們）被託付的幸福與約定——超越它們，繼續前行。」注意這句歌詞**沒有主語**：誰被託付？誰在前行？日文歌詞很常省略主語，讓聽的人自己填空。對聽過《炎》的人來說，答案很明顯：被託付的，是留下來的我們；前行的，也是留下來的我們。

## 🎯 文法重點：受身形「〜される」與「〜て行く」

### 1. 受身形：託す → 託される（被託付）

日文的**受身（うけみ）**，就是中文的「被動」：表示「被～怎麼樣」。例如「老師稱讚我」是主動，「我被老師稱讚」就是受身。

動詞要變成受身，必須做「活用」（改變動詞的形狀）。基本規則如下：

| 動詞種類 | 變化規則 | 例子 |
|---|---|---|
| 五段動詞（う段結尾） | 最後的う段假名改成あ段 ＋ れる | 託す → 託される、書く → 書かれる |
| 一段動詞（える／いる結尾） | 去掉 る ＋ られる | 食べる → 食べられる |
| する動詞 | する → される | 約束する → 約束される |

<ruby>託<rt>たく</rt></ruby>す 是**五段動詞**，所以受身形是「託される」＝「被託付」。再加上**た形**（過去），就變成「託された」＝「被託付了」。歌詞用過去形，是因為那份託付已經發生了——煉獄さん在消逝之前，已經把幸福與約定交到了留下來的人手上。

> 小知識：怎麼判斷動詞是「五段」還是「一段」？最簡單的方法看**辭書形（原形）的結尾**：結尾是「える／いる」的，大多是**一段動詞**（如：食べる、見る）；結尾是其他う段假名（す、く、む、ぶ、る…）的，大多是**五段動詞**（如：託す、書く、帰る）。不過也有例外（如：帰る、入る 雖然是「る」結尾，卻是五段動詞），所以碰到不確定的動詞，查字典最保險。詳細的變化規則可以看[[posts/japanese-learning/grammar/verb-conjugation|日文動詞變化規則]]。

**例句1**：<ruby>託<rt>たく</rt></ruby>されたもの <button class="pronunciation-play-btn" data-text="託されたもの">🔊</button>
— 被託付的事物。（受身＋た形，和歌詞的「託された」一模一樣）

**例句2**：<ruby>命<rt>いのち</rt></ruby>を<ruby>託<rt>たく</rt></ruby>される <button class="pronunciation-play-btn" data-text="命を託される">🔊</button>
— 被託付性命。（把最重要的東西交給對方）

**例句3**：<ruby>先<rt>せん</rt></ruby><ruby>生<rt>せい</rt></ruby>に<ruby>褒<rt>ほ</rt></ruby>められる <button class="pronunciation-play-btn" data-text="先生に褒められる">🔊</button>
— 被老師稱讚。（最常見的受身例句。小知識：受身句裡「被誰」用助詞 に 標示）

**歌詞應用**：歌詞的「託された」沒有寫「被誰託付」——但聽過《無限列車篇》的人都知道，託付者是煉獄杏壽郎。用受身而不是主動形（託した），是因為主角不是自己去搶幸福，而是**從重要的人那裡接下**這份幸福與約定。受身把「接受者」放在句子的中心，正好表現出「我們是被託付的一方」。

### 2. 「〜て行く」：超越之後，繼續前行

<ruby>超<rt>こ</rt></ruby>える（こえる）是「超越、越過」，て形是「超えて」。後面的 <ruby>行<rt>い</rt></ruby>く（いく）在這裡不是「去哪裡」的本意，而是**補助動詞**，接在て形後面有兩種常見語感：

1. **空間**：一邊做某動作、一邊往遠處移動。例：<ruby>走<rt>はし</rt></ruby>っていく（跑過去）。
2. **時間**：動作持續進行、往未來延伸。例：<ruby>生<rt>い</rt></ruby>きていく（繼續活下去）。

歌詞的「超えて行く」兩個語感都有：先「超越」（跨過悲傷與過去），然後「繼續前行」（往未來走下去）。て形把兩個動作串在一起：**越過之後，腳步不停**。之前學過的「[[posts/japanese-learning/lyrics/homura/homura-oto-wo-tatete-kuzureochite|音を立てて崩れ落ちて行く]]」裡的「崩れ落ちて行く」也是同樣的「〜て行く」構造，可以對照著看。

**例句1**：<ruby>期<rt>き</rt></ruby><ruby>待<rt>たい</rt></ruby>を<ruby>超<rt>こ</rt></ruby>える <button class="pronunciation-play-btn" data-text="期待を超える">🔊</button>
— 超越期待。（超える 的基本用法）

**例句2**：<ruby>過<rt>か</rt></ruby><ruby>去<rt>こ</rt></ruby>を<ruby>超<rt>こ</rt></ruby>えて<ruby>行<rt>い</rt></ruby>く <button class="pronunciation-play-btn" data-text="過去を超えて行く">🔊</button>
— 超越過去，繼續前行。（和歌詞完全相同的結構）

**例句3**：<ruby>約束<rt>やくそく</rt></ruby>を<ruby>守<rt>まも</rt></ruby>る <button class="pronunciation-play-btn" data-text="約束を守る">🔊</button>
— 遵守約定。（約束 最常見的搭配動詞是 守る）

**例句4（呼應歌詞）**：<ruby>約束<rt>やくそく</rt></ruby>を<ruby>超<rt>こ</rt></ruby>えて<ruby>行<rt>い</rt></ruby>く <button class="pronunciation-play-btn" data-text="約束を超えて行く">🔊</button>
— 超越約定，繼續前行。（和歌詞一模一樣的結構！）

> 小知識：「超える」和「越える」都讀「こえる」，意思也很接近（都有「越過」的意思）。「超える」偏向「**超過某個標準**」（如：超過期待、超過時速），「越える」偏向「**越過某個障礙／界線**」（如：越過山、越過國境）。歌詞的「約束を超えて行く」用的是「超える」，強調「超過了約定本身的重量」——因為背負得太重，所以必須超越它，才能繼續走。另外，歌詞裡的 と 是**並列助詞**（幸福**和**約定）；日文的 と 還有「引用」用法（如：〜と言う＝說～），兩者長得一樣但角色不同，初學者可以特別留意。

**歌詞應用**：整句「託された幸せと 約束を超えて行く」＝背負著被託付的幸福與約定，向前超越、繼續前行。注意「超越」的對象不是敵人，而是**悲傷與過去**——正因為背負著重要之人的託付，所以不能停在原地哭泣；要連同那份幸福與約定一起，越過這份失去，繼續走向未來。

### 歌詞的畫面：背負著託付，向前超越

最後，把整句合起來看：

1. **託された（被託付）**：受身＋過去。煉獄さん消逝之前，已經把幸福與約定交給留下來的人——這份託付是「已經發生的事實」。
2. **幸せと 約束（幸福與約定）**：並列助詞 と 把兩樣最重要的東西綁在一起：煉獄さん留下的，不只是回憶，還有幸福與約定。
3. **超えて行く（超越前行）**：て形＋補助動詞。越過悲傷，然後繼續走下去——不是忘記，而是帶著它們前進。

這正是《炎》最動人的轉折：上一句「<ruby>輝<rt>かがや</rt></ruby>いて<ruby>消<rt>き</rt></ruby>えてった <ruby>未来<rt>みらい</rt></ruby>のために」還在描寫那道光芒的消逝，這一句立刻把鏡頭轉回留下來的人——**他們沒有停下來，而是背負著被託付的幸福與約定，超越悲傷，繼續前行**。對看過《無限列車篇》的人來說，這就是炭治郎他們接下煉獄さん的託付、擦乾眼淚繼續變強的畫面。

而下一句「<ruby>振<rt>ふ</rt></ruby>り<ruby>返<rt>かえ</rt></ruby>らずに<ruby>進<rt>すす</rt></ruby>むから」（因為會不回頭地前進）馬上解釋了為什麼要「超えて行く」：因為前進，就是對託付最好的回答。
