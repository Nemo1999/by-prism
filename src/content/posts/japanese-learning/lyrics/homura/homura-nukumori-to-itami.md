# 炎 — 「ぬくもりと痛みに間に合うように」

> ぬくもりと<ruby>痛<rt>いた</rt></ruby>みに<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>うように <button class="pronunciation-play-btn" data-text="ぬくもりと痛みに間に合うように">🔊 播放</button>
> 中文翻譯：為了能趕上那份溫暖與疼痛。

這一句緊接在「<ruby>去<rt>さ</rt></ruby>りゆく<ruby>背中<rt>せなか</rt></ruby>に<ruby>伝<rt>つた</rt></ruby>えたくて（好想傳達給那離去的背影）」之後，是那句話的「目的」——為什麼好想傳達？因為「為了能趕上那份溫暖與疼痛」。主角眼看著重要的人一步步遠去，拼命想把心裡的話在還來得及的時候送到對方身邊。

這一句對初學者來說是寶藏，因為它同時包含兩個超實用的日文表達：一個是慣用表現「<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う（趕上、來得及）」，另一個是表示目的「為了能…」的「ように」。兩個都是日常對話中超高頻率的用法，學會之後馬上就能用！我們一個詞一個詞來拆解吧。

## 📖 逐字分析

- **ぬくもり** <button class="pronunciation-play-btn" data-text="ぬくもり">🔊</button>：名詞，溫暖、暖意。不是「<ruby>温度<rt>おんど</rt></ruby>（溫度）」那種冷熱的數字，而是心裡或肌膚感受到的、讓人安心的暖意。日文寫成漢字是「<ruby>温<rt>ぬく</rt></ruby>もり」，這首歌刻意用平假名寫，讀起來更柔軟、更溫暖。
- **と** <button class="pronunciation-play-btn" data-text="と">🔊</button>：並列助詞，「和、跟」。功能像中文的「和」，把「ぬくもり（溫暖）」和「<ruby>痛<rt>いた</rt></ruby>み（疼痛）」兩個名詞連結成一個整體：「溫暖與疼痛」。
- **<ruby>痛<rt>いた</rt></ruby>み**（いたみ）<button class="pronunciation-play-btn" data-text="痛み">🔊</button>：名詞，疼痛、痛苦。對應的動詞是「<ruby>痛<rt>いた</rt></ruby>む（疼痛）」。這裡和「ぬくもり」並列，代表「快樂與痛苦、美好與悲傷」——那些和對方一起經歷的一切。
- **に** <button class="pronunciation-play-btn" data-text="に">🔊</button>：對象／方向助詞。在這裡表示「<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う」的對象，也就是「要趕上的目標」是「ぬくもりと<ruby>痛<rt>いた</rt></ruby>み（溫暖與疼痛）」。
- **<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う**（まにあう）<button class="pronunciation-play-btn" data-text="間に合う">🔊</button>：動詞（慣用表現），趕上、來得及。由「<ruby>間<rt>ま</rt></ruby>（空隙、時間）」＋「に」＋「<ruby>合<rt>あ</rt></ruby>う（符合）」組成，字面是「剛好嵌進那個空隙」，引申為「趕上、來得及」。詳細用法見下面的文法重點！
- **ように** <button class="pronunciation-play-btn" data-text="ように">🔊</button>：目的表現，「為了能…」。接在動詞後面，表示「希望達成某個目標」。這裡接在「<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う」後面，變成「為了能趕上…」。

💡 給初學者的小提示：這一句其實**沒有主要動詞**！「ように」是接在動詞後面的，但真正想做的動作（例如「<ruby>伝<rt>つた</rt></ruby>えたい（好想傳達）」「<ruby>届<rt>とど</rt></ruby>けたい（好想送到）」）被省略了，只留下目的。日文歌詞為了節奏和意境，常常這樣把動詞留白，讓聽的人自己感受。

## 🎯 文法重點：慣用表現「間に合う」與目的表現「〜ように」

### ① 慣用表現「間に合う」（まにあう）— 趕上、來得及

「<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う」是日文中非常常用的**慣用表現**。所謂慣用表現，就是幾個字組合在一起後，意思不能照字面一個字一個字拼出來，要當作一個完整的詞來記。

**字面拆解**（幫助記憶用）：

```
間（ま）＝時間或空間的「空隙」
に ＝助詞（在…之中）
合う（あう）＝符合、吻合
→「剛好嵌進那個空隙」→ 趕上、來得及
```

「間に合う」是**五段動詞**，變化方式如下：

| 形 | 日文 | 意思 |
|---|---|---|
| 基本形 | <ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う | 趕上、來得及 |
| 否定形 | <ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>わない | 趕不上、來不及 |
| て形 | <ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>って | 趕上了（連接後面的句子） |
| 過去形 | <ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>った | 趕上了（過去） |

**例句1**：<ruby>電車<rt>でんしゃ</rt></ruby>に<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う <button class="pronunciation-play-btn" data-text="電車に間に合う">🔊</button>
— 趕上電車。（在電車開走之前抵達車站）

**例句2**：<ruby>締<rt>し</rt></ruby>め<ruby>切<rt>き</rt></ruby>りに<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う <button class="pronunciation-play-btn" data-text="締め切りに間に合う">🔊</button>
— 趕上截止（期限）。（在截止時間之前完成）

**例句3**：もう<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>わない <button class="pronunciation-play-btn" data-text="もう間に合わない">🔊</button>
— 已經來不及了。（否定形「間に合わない」＋「もう（已經）」，是口語中超常說的句子）

**例句4**：<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>ってよかった <button class="pronunciation-play-btn" data-text="間に合ってよかった">🔊</button>
— 趕上了真好。（て形「間に合って」＋「よかった（太好了）」，表達鬆了一口氣的心情）

### ② 目的表現「〜ように」— 為了能…

「ように」接在動詞後面，可以表示**目的**：「為了能…」「為了不…」。這和歌詞裡的用法一模一樣。

**基本結構**：

```
動詞辞書形 ＋ ように → 為了能…
動詞ない形 ＋ ように → 為了不…
例：忘れない ＋ ように → 為了不忘記
```

**小提醒**：「ように」來自「よう（様子、樣子）」，和「ようだ（好像）」是親戚，但這裡不是「好像」的意思，而是「目的」。日文中「よう」家族有很多用法，初學者先記住「動詞＋ように＝為了能…」這個最實用的就好！

**例句1**：<ruby>忘<rt>わす</rt></ruby>れないようにメモする <button class="pronunciation-play-btn" data-text="忘れないようにメモする">🔊</button>
— 為了不忘記而寫筆記。（「忘れない（不忘記）」＋「ように（為了…）」＋「メモする（寫筆記）」）

**例句2**：<ruby>聞<rt>き</rt></ruby>こえるように<ruby>大<rt>おお</rt></ruby>きい<ruby>声<rt>こえ</rt></ruby>で<ruby>話<rt>はな</rt></ruby>す <button class="pronunciation-play-btn" data-text="聞こえるように大きい声で話す">🔊</button>
— 為了讓對方聽得見而大聲說話。

**例句3**：<ruby>風邪<rt>かぜ</rt></ruby>をひかないように<ruby>気<rt>き</rt></ruby>をつける <button class="pronunciation-play-btn" data-text="風邪をひかないように気をつける">🔊</button>
— 為了不感冒而注意身體。（「ない形＋ように」＝為了不…）

**例句4**（呼應歌詞的用法）：<ruby>言葉<rt>ことば</rt></ruby>が<ruby>届<rt>とど</rt></ruby>くように<ruby>祈<rt>いの</rt></ruby>る <button class="pronunciation-play-btn" data-text="言葉が届くように祈る">🔊</button>
— 為了讓話語能傳達而祈禱。（和歌詞一樣，都是「希望某件事能實現」的願望！）

### 歌詞應用

把兩個文法合起來看，「ぬくもりと<ruby>痛<rt>いた</rt></ruby>みに<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>うように」就是：

```
（言葉を）ぬくもりと痛みに間に合うように（伝えたい）
（把話語）為了能趕上溫暖與疼痛（而想傳達）
```

「ぬくもりと<ruby>痛<rt>いた</rt></ruby>み」指的是和對方一起經歷的、有笑有淚的種種回憶；「<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>うように」則是「趁還來得及的時候」。合起來就是：**主角想把滿腔的話語，趁著還來得及的時候，送到那個正在離去的人身邊**——趕上那些溫暖與疼痛的回憶，趕上對方還沒走遠的背影。

為什麼要強調「趕上」？因為對方正在離開（上一句的「<ruby>去<rt>さ</rt></ruby>りゆく<ruby>背中<rt>せなか</rt></ruby>」）。一旦錯過，就永遠來不及了。「間に合う」這個詞本身就帶著「時間緊迫、再不行動就糟了」的焦急感，所以這一句雖然沒有直接說「好想哭」，卻把那份「拚命想留住什麼」的迫切心情完全傳達出來了。

### 📝 重點複習

- 「<ruby>間<rt>ま</rt></ruby>に<ruby>合<rt>あ</rt></ruby>う」是慣用表現，意思是「趕上、來得及」，否定形是「間に合わない（來不及）」。
- 常用搭配：<ruby>電車<rt>でんしゃ</rt></ruby>に間に合う（趕上電車）、<ruby>締<rt>し</rt></ruby>め<ruby>切<rt>き</rt></ruby>りに間に合う（趕上截止）。
- 「動詞辞書形／ない形＋ように」表示目的「為了能…／為了不…」。
- 歌詞「ぬくもりと<ruby>痛<rt>いた</rt></ruby>みに間に合うように」＝想把話語及時傳達給對方，趁還來得及的時候。
- 歌詞省略了主要動詞（如「伝えたい」），只留下目的「ように」，這是日文歌詞常見的留白手法。
