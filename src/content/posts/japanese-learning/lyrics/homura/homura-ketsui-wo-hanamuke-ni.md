# 炎 — 「強くなりたいと願い 泣いた 決意を餞に」

> <ruby>強<rt>つよ</rt></ruby>くなりたいと<ruby>願<rt>ねが</rt></ruby>い <ruby>泣<rt>な</rt></ruby>いた <ruby>決意<rt>けつい</rt></ruby>を<ruby>餞<rt>はなむけ</rt></ruby>に <button class="pronunciation-play-btn" data-text="強くなりたいと願い 泣いた 決意を餞に">🔊 播放</button>
> 中文翻譯：祈願著想要變得更強、哭著，以那份決心作為餞別。

這一句是《炎》中主角心情最糾結的時刻：明明捨不得，卻還是哭著許下「我要變強」的願望，並且把這份流著淚的決心，當作送給即將離開之人的餞別禮物。沒有華麗的辭藻，卻把「悲傷＋溫柔＋覺悟」三種情感濃縮在短短一句裡。

對日文初學者來說，這句更是寶藏：有願望用法「〜たい」，有「把…當作…」的「〜を<ruby>餞<rt>はなむけ</rt></ruby>に」，還有「連用中止形」「た形接續」這些日文歌詞超愛用的連接手法。我們一個一個拆解吧！

## 📖 逐字分析

- **<ruby>強<rt>つよ</rt></ruby>く**（つよく）<button class="pronunciation-play-btn" data-text="強く">🔊</button>：形容詞「<ruby>強<rt>つよ</rt></ruby>い（強大的）」的連用形（く形）。形容詞要把詞尾的「い」變成「く」，才能接在動詞前面，這裡接「なる（變成）」，表示「變成強大」。
- **なりたい**（なりたい）<button class="pronunciation-play-btn" data-text="なりたい">🔊</button>：想要變成。「なる（變成）」＋願望助動詞「たい（想要）」＝「なりたい」。「<ruby>強<rt>つよ</rt></ruby>く」＋「なりたい」＝「<ruby>強<rt>つよ</rt></ruby>くなりたい（想要變強）」。
- **と**（と）<button class="pronunciation-play-btn" data-text="と">🔊</button>：引用助詞，用來標記前面「心裡想／祈願的內容」，中文可以理解成「…（這件事）」。這裡表示主角心中祈願的內容就是「<ruby>強<rt>つよ</rt></ruby>くなりたい」。
- **<ruby>願<rt>ねが</rt></ruby>い**（ねがい）<button class="pronunciation-play-btn" data-text="願い">🔊</button>：這裡是動詞「<ruby>願<rt>ねが</rt></ruby>う（祈願、懇求）」的連用中止形，用來把句子停一下再接下去，等於「祈願著…、（然後）…」。另外「<ruby>願<rt>ねが</rt></ruby>い」單獨使用時是名詞，意思是「願望」。
- **<ruby>泣<rt>な</rt></ruby>いた**（ないた）<button class="pronunciation-play-btn" data-text="泣いた">🔊</button>：動詞「<ruby>泣<rt>な</rt></ruby>く（哭）」的た形（過去式），意思是「哭了」。這裡的「た形」和「て形」一樣有「連接下一句」的功能，等於「哭了、（然後）…」。
- **<ruby>決意<rt>けつい</rt></ruby>**（けつい）<button class="pronunciation-play-btn" data-text="決意">🔊</button>：名詞，決心、下定決心的意志。和「<ruby>決心<rt>けっしん</rt></ruby>」意思相近，但「決意」更強調「自己在心中做出的堅定選擇」，帶有「覺悟」的味道。
- **を**（を）<button class="pronunciation-play-btn" data-text="を">🔊</button>：受格助詞（對象助詞），標記動作的對象。這裡的動作是「<ruby>餞<rt>はなむけ</rt></ruby>にする（當作餞別）」，對象就是「<ruby>決意<rt>けつい</rt></ruby>」。
- **<ruby>餞<rt>はなむけ</rt></ruby>**（はなむけ）<button class="pronunciation-play-btn" data-text="餞">🔊</button>：名詞，餞別、送行時送給對方的禮物或祝福。「はなむけ」是日文固有的訓讀，漢字「餞」比較少見，平常多半直接寫假名「はなむけ」。另外「<ruby>餞別<rt>せんべつ</rt></ruby>」也是常見的說法。
- **に**（に）<button class="pronunciation-play-btn" data-text="に">🔊</button>：助詞，這裡表示「作為、當作」。和前面的「を」組成「〜を…にする＝把…當作…」的句型，所以「<ruby>決意<rt>けつい</rt></ruby>を<ruby>餞<rt>はなむけ</rt></ruby>に」就是「把決心當作餞別」。

💡 給初學者的小辭典：日文動詞有所謂的「活用形」，就是動詞會依照後面接的東西改變尾巴。例如「<ruby>泣<rt>な</rt></ruby>く」接「ます」變成「<ruby>泣<rt>な</rt></ruby>きます」，接「た」變成「<ruby>泣<rt>な</rt></ruby>いた」。「連用形」是其中最重要的一種，詳細規則可以看文末的「日文動詞變化規則」連結。

## 🎯 文法重點：〜たい 與 〜を餞に

### (1) 〜たい — 願望「想要…」

「たい」是日文表達「想要…」最常用的方式，接在動詞「ます形去掉ます」的後面（也就是連用形）：

```
動詞ます形（去掉ます）＋ たい
なる   → なります → なりたい（想要變成）
行く   → 行きます → 行きたい（想去）
食べる → 食べます → 食べたい（想吃）
泣く   → 泣きます → 泣きたい（想哭）
```

「たい」本身會像い形容詞一樣變化：否定是「〜たくない（不想要）」，過去是「〜たかった（曾經想要）」。例如「<ruby>強<rt>つよ</rt></ruby>くなりたくない」＝「不想變強」。

**例句1**：<ruby>大<rt>だい</rt></ruby><ruby>学<rt>がく</rt></ruby>に<ruby>行<rt>い</rt></ruby>きたい <button class="pronunciation-play-btn" data-text="大学に行きたい">🔊</button>
— 想去大學。

**例句2**：<ruby>強<rt>つよ</rt></ruby>くなりたい <button class="pronunciation-play-btn" data-text="強くなりたい">🔊</button>
— 想變強。（和歌詞完全一樣！）

**例句3**：<ruby>食<rt>た</rt></ruby>べたいものが<ruby>多<rt>おお</rt></ruby>い <button class="pronunciation-play-btn" data-text="食べたいものが多い">🔊</button>
— 想吃的東西很多。（「<ruby>食<rt>た</rt></ruby>べたいもの」＝「想吃的東西」，「たい形」可以直接修飾後面的名詞）

**例句4**：<ruby>水<rt>みず</rt></ruby>を<ruby>飲<rt>の</rt></ruby>みたい <button class="pronunciation-play-btn" data-text="水を飲みたい">🔊</button>
— 想喝水。

**歌詞應用**：「<ruby>強<rt>つよ</rt></ruby>くなりたい」就是「想要變成強大」。形容詞「<ruby>強<rt>つよ</rt></ruby>い」先變成連用形「<ruby>強<rt>つよ</rt></ruby>く」，再接動詞「なる（變成）」，最後加上「たい」。主角不是「已經很強」，而是「想要變強」——這份「還沒有達成、所以拼命渴望」的心情，正是整句歌詞的起點。

### (2) 「〜を餞に」— 以…作為餞別

「<ruby>餞<rt>はなむけ</rt></ruby>」是「餞別、送行禮物」，「〜を<ruby>餞<rt>はなむけ</rt></ruby>に（＋する／<ruby>贈<rt>おく</rt></ruby>る）」是「把…當作餞別」的文語／慣用表達。現代口語比較常說「〜を<ruby>餞別<rt>せんべつ</rt></ruby>として」或「〜をはなむけとして」，意思相同，但「〜を<ruby>餞<rt>はなむけ</rt></ruby>に」更有歌詞、書面的文藝感。

```
名詞 ＋ を ＋ 餞 ＋ に（＋ する／贈る）
決意 ＋ を ＋ はなむけ ＋ に（する）
→ 把決心當作餞別
```

**例句1**：この<ruby>歌<rt>うた</rt></ruby>を<ruby>餞<rt>はなむけ</rt></ruby>に<ruby>贈<rt>おく</rt></ruby>る <button class="pronunciation-play-btn" data-text="この歌を餞に贈る">🔊</button>
— 以這首歌作為餞別贈送。

**例句2**：<ruby>餞<rt>はなむけ</rt></ruby>の<ruby>言<rt>こと</rt></ruby><ruby>葉<rt>ば</rt></ruby>を<ruby>送<rt>おく</rt></ruby>る <button class="pronunciation-play-btn" data-text="餞の言葉を送る">🔊</button>
— 送上餞別的話語。（「<ruby>餞<rt>はなむけ</rt></ruby>の<ruby>言<rt>こと</rt></ruby><ruby>葉<rt>ば</rt></ruby>」是「送行時說的話」的固定說法）

**例句3**：この<ruby>写<rt>しゃ</rt></ruby><ruby>真<rt>しん</rt></ruby>を<ruby>餞<rt>はなむけ</rt></ruby>に <button class="pronunciation-play-btn" data-text="この写真を餞に">🔊</button>
— 以這張照片作為餞別。（和歌詞一樣省略動詞，讓句子停在「に」，反而更有餘韻）

**歌詞應用**：歌詞「<ruby>決意<rt>けつい</rt></ruby>を<ruby>餞<rt>はなむけ</rt></ruby>に」就是「把決心當作餞別」。主角哭著許願要變強，這份「流著淚的決心」，就是送給離開之人的餞別禮物——不是具體的東西，而是「我一定會變強」的誓言。離別的人帶走的不是紀念品，而是主角的覺悟，這就是《炎》最溫柔也最悲傷的地方。

💡 文化小知識：「はなむけ」據說來自「<ruby>馬<rt>うま</rt></ruby>の<ruby>鼻<rt>はな</rt></ruby>を<ruby>向<rt>む</rt></ruby>ける（把馬的鼻子轉向出發的方向）」——古時候送人遠行，會把馬頭轉向旅行的方向，幫對方「上路」。所以「はなむけ」本來是「送人啟程」的意思，後來演變成「送行時的禮物／祝福」。漢字「餞」也同樣帶有「為遠行的人送別」的意思，是不是很有趣？

### 整句結構：三個動作的連鎖

這句歌詞其實是三個動作排在一起：

1. <ruby>強<rt>つよ</rt></ruby>くなりたいと<ruby>願<rt>ねが</rt></ruby>い（祈願想要變強）→ 用連用中止形連接
2. <ruby>泣<rt>な</rt></ruby>いた（哭了）→ 用た形連接
3. <ruby>決意<rt>けつい</rt></ruby>を<ruby>餞<rt>はなむけ</rt></ruby>に（把決心當作餞別）→ 句子結尾

「<ruby>願<rt>ねが</rt></ruby>い」的連用中止形和「<ruby>泣<rt>な</rt></ruby>いた」的た形，在這裡都扮演「接著說下去」的角色，就像中文的「…著、…，然後…」。三個動作循序漸進：先許願、再流淚、最後下定決心送別——眼淚不是軟弱，而是這份決心的證據。

### 📝 重點複習

- 「〜たい」＝「想要…」，接在動詞ます形去掉ます的連用形後面；「<ruby>強<rt>つよ</rt></ruby>くなりたい」＝「想要變強」。
- 「<ruby>餞<rt>はなむけ</rt></ruby>」＝「餞別、送行禮物」；「〜を<ruby>餞<rt>はなむけ</rt></ruby>に」＝「以…作為餞別」。
- 連用中止形（<ruby>願<rt>ねが</rt></ruby>い）和た形（<ruby>泣<rt>な</rt></ruby>いた）都可以用來連接句子，歌詞中非常常見。
- 這句歌詞＝「祈願著想要變強、哭了，把這份決心當作送你的餞別」。
