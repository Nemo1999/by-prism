# 🎵 日文學習：透過歌曲學日文

> 語言學習不應該是枯燥的背誦，而是與情感和興趣連結的美好體驗。

## 🍋 目前教材：《Lemon》— 米津玄師

### 為什麼是《Lemon》？
- **發音清晰**：米津玄師的發音非常標準
- **速度適中**：節奏適合跟讀學習
- **情感豐富**：歌詞容易產生共鳴
- **文法多元**：涵蓋假設條件、比喻、慣用表達等重要文法

## 🧰 學習方法

1. **聽**：先欣賞歌曲，感受旋律
2. **讀**：看歌詞，理解意思（點擊 🔊 聽發音）
3. **說**：跟著朗讀，練習發音
4. **唱**：跟著歌曲演唱，培養語感

**原則**：不用羅馬拼音，直接學假名，建立純正語感。
