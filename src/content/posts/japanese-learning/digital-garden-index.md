# 日文學習數位花園

> 這不是一個線性課程，而是一個有機生長的知識生態系統。

## 🌱 核心理念

### 從線性到網狀
傳統學習：A → B → C → D （固定路徑）  
數位花園：A ↔ B ↔ C ↔ D （自由探索）

### 學習哲學
我們相信：
1. **學習是探索**，不是跟隨
2. **知識是網絡**，不是序列
3. **路徑是個人**，不是標準
4. **成長是有機**，不是機械

## 💡 學習心法集成

### 探索心法
1. **漫遊學習**：像在花園中散步一樣隨意探索
2. **深度挖掘**：對感興趣的點深入學習
3. **橫向連結**：發現知識點之間的關聯
4. **個人路徑**：創造屬於自己的學習路徑

### 記憶心法
1. **網絡記憶**：在連結中記憶，不在孤立中記憶
2. **情境記憶**：在具體情境中記憶
3. **情感記憶**：透過情感連結加強記憶
4. **應用記憶**：在使用中鞏固記憶

### 應用心法
1. **即學即用**：學了就在實際中嘗試使用
2. **錯誤學習**：從錯誤中學習，不害怕犯錯
3. **創造學習**：創造自己的例句和應用
4. **分享學習**：透過分享加深理解

1. **學習應該自由**：每個人有自己的學習節奏和路徑
