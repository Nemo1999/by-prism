# 編輯設定指南 - 簡明扼要

## 🎯 核心原則
**所有編輯必須遵照模板，保持簡明扼要**

## 📝 內容要求

### 1. 字數限制
- 單字卡片：300-500字
- 文法概念：400-600字  
- 歌詞解析：500-800字
- 完整歌詞：800-1200字
- **絕對上限：1500字**

### 2. 內容結構
**必須包含：**
1. 基本資訊（標題、描述、標籤）
2. 核心內容（文法解釋、例句）
3. 相關連結（wikilinks）

**必須刪除：**
1. 文化學習重點
2. 學習心法區塊
3. 發音練習區塊
4. 互動學習區塊
5. 冗長的背景介紹

### 3. 文法與例句
- 每個文法點提供 **2個例句**
- 例句必須有拼音標註：`<ruby>漢字<rt>ふりがな</rt></ruby>`
- 例句必須有中文翻譯

## 🔗 連結格式

### Wikilink 規則
```
[[posts/完整路徑/ascii檔名|顯示文字]]
```

**正確範例：**
- `[[posts/japanese-learning/lyrics/lemon-yume-naraba|夢ならばどれほどよかったでしょう]]`
- `[[posts/japanese-learning/vocabulary/yume|夢]]`

**錯誤範例：**
- `[[夢]]` (缺少完整路徑)
- `[[yume]]` (缺少顯示文字)

### 外部連結
- 使用標準Markdown連結：`[顯示文字](URL)`
- 外部資源保持為外部連結，不創建內部頁面

## 📋 品質檢查清單

### 創建前檢查
- [ ] 選擇正確的模板
- [ ] 確認字數目標
- [ ] 準備2個文法例句

### 創建後檢查  
- [ ] 字數符合限制
- [ ] 刪除了所有必須刪除的內容
- [ ] 包含2個文法例句
- [ ] 所有日文漢字有拼音標註
- [ ] wikilink使用完整路徑格式
- [ ] 內容聚焦於文法解釋

## 🎵 歌曲相關頁面規範

### 完整歌詞頁面
**結構：**
1. 日文歌詞（每句連結到詳細解析）
2. 中文翻譯（整首放在最後）
3. 相關內容連結

**要求：**
- 保持歌詞完整性
- 只為已解析的歌詞句添加連結
- 中文翻譯簡潔準確

### 歌詞解析頁面
**結構：**
1. 逐字分析
2. 文法結構
3. 學習重點（文法為主）
4. 應用例句（2個）
5. 相關內容連結
