# 閉める（しめる）

> 關上、關閉（五段動詞）

## 📖 基本資訊
- **讀音**：<ruby>閉<rt>し</rt></ruby>める
- **詞性**：五段動詞（他動詞、マ行）
- **意思**：關上、關閉（門、窗、蓋子等）
- **對應自動詞**：閉まる（しまる）

## 🎯 文法與用法

日常最常用的「關門/窗」動詞。

**例句1**：ドアを<ruby>閉<rt>し</rt></ruby>めてください — 請關門。

**例句2**：<ruby>窓<rt>まど</rt></ruby>を<ruby>閉<rt>し</rt></ruby>めた — 關了窗戶。

### 變化形（五段マ行）

| 活用形 | 變化 |
|---|---|
| 辞書形 | 閉める |
| ない形 | 閉めない |
| て形 | 閉めて |
| た形 | 閉めた |
| 受身形 | 閉められる |
| 可能形 | 閉められる |
| 意向形 | 閉めよう |

> 五段マ行遵循「ぬ・ぶ・む」組：て形→んで、た形→んだ。しめる → しめて / しめた。
