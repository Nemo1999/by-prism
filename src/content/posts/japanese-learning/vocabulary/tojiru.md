# 閉じる（とじる）

> 關上、闔上（一段動詞）

## 📖 基本資訊
- **讀音**：<ruby>閉<rt>と</rt></ruby>じる
- **詞性**：一段動詞（他動詞）
- **意思**：關上、闔上（書本、門、眼睛、窗簾等）
- **對應自動詞**：閉まる（しまる）—「（門自己）關上」

## 🎯 文法與用法

用於表示人為地將某物關上或闔上。

**例句1**：<ruby>目<rt>め</rt></ruby>を<ruby>閉<rt>と</rt></ruby>じて<ruby>考<rt>かんが</rt></ruby>える — 閉上眼睛思考。

**例句2**：<ruby>本<rt>ほん</rt></ruby>を<ruby>閉<rt>と</rt></ruby>じた — 闔上了書。

### 變化形（一段動詞：去る＋語尾）

| 活用形 | 變化 |
|---|---|
| 辞書形 | 閉じる |
| ない形 | 閉じない |
| て形 | 閉じて |
| た形 | 閉じた |
| 受身形 | 閉じられる |
| 可能形 | 閉じられる |
| 意向形 | 閉じよう |

### vs 閉める（しめる）

| | 閉じる | 閉める |
|---|---|---|
| 類型 | 一段動詞 | 五段動詞 |
| 對象 | 書、眼睛、窗簾 | 門、窗戶 |
| 語感 | 較正式/文學 | 日常口語 |

## 🎵 歌曲應用

- **《すずめ》**：「<ruby>閉<rt>と</rt></ruby>じたはずの<ruby>部屋<rt>へや</rt></ruby>」— 應該已關上的房間
