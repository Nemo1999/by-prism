# 結ぶ（むすぶ）

> 連結、締結、打結（五段動詞）

## 📖 基本資訊
- **讀音**：<ruby>結<rt>むす</rt></ruby>ぶ
- **詞性**：五段動詞（他動詞、バ行）
- **意思**：連結、繫結、締結（關係/條約）、打結
- **對應自動詞**：結ばれる（受身形）

## 🎯 文法與用法

用於表示物理上的「打結/綁起」或抽象上的「連結/締結」。

**例句1**：<ruby>靴<rt>くつ</rt></ruby>ひもを<ruby>結<rt>むす</rt></ruby>んだ — 綁好了鞋帶。

**例句2**：<ruby>二人<rt>ふたり</rt></ruby>の<ruby>縁<rt>えにし</rt></ruby>を<ruby>結<rt>むす</rt></ruby>ぶ — 締結兩人的緣分。

### 變化形（五段バ行）

| 活用形 | 變化 |
|---|---|
| 辞書形 | 結ぶ |
| ない形 | 結ばない |
| て形 | 結んで |
| た形 | 結んだ |
| 受身形 | 結ばれる |
| 可能形 | 結べる |
| 意向形 | 結ぼう |

> 五段バ行遵循「ぬ・ぶ・む」組：て形→んで、た形→んだ。

## 🎵 歌曲應用

- **《すずめ》**：「それらが<ruby>結<rt>むす</rt></ruby>ばれるのは<ruby>心<rt>しん</rt></ruby>の<ruby>臓<rt>ぞう</rt></ruby>」— 它們被連結在一起的地方是心臟（受身形）
