# 日文動詞變化規則 — 完整基礎

> 掌握日文動詞的三大類別與六種核心活用形。這是日文文法的根基。

## 📚 日文動詞的分類

日文動詞分為三大類：

| 類別 | 描述 | 數量 | 特徵 |
|---|---|---|---|
| **五段動詞** | 活用時詞尾在五個段變化 | 最多 | 非る結尾，或特殊る |
| **一段動詞** | 去掉る後直接加語尾 | 較少 | い段/え段 + る |
| **不規則動詞** | 不遵循規則 | 2個 | する、来る |

### 如何快速辨識？

```
辭書形看結尾：
  ├── 不是「る」結尾 → 五段動詞（書く、読む、話す...）
  └── 是「る」結尾
        ├── る前是「あ・う・お」段 → 五段動詞（ある、作る、取る）
        ├── る前是「い・え」段
        │     ├── 多數 → 一段動詞（食べる、起きる、閉じる）
        │     └── 少數例外 → 五段動詞（走る、入る、帰る、切る...）
        └── する、来る → 不規則動詞
```

## 🔄 六種核心活用形

### 活用形總覽（以代表性動詞為例）

| 活用形 | 五段：書く | 五段：読む | 五段：ある | 一段：食べる | 不規則：する | 不規則：来る |
|---|---|---|---|---|---|---|
| **辞書形** | 書く | 読む | ある | 食べる | する | 来る（くる） |
| **ない形** | 書かない | 読まない | **ない** | 食べない | しない | 来ない（こない） |
| **て形** | 書いて | 読んで | あって | 食べて | して | 来て（きて） |
| **た形** | 書いた | 読んだ | あった | 食べた | した | 来た（きた） |
| **ば形** | 書けば | 読めば | あれば | 食べれば | すれば | 来れば（くれば） |
| **意向形** | 書こう | 読もう | あろう | 食べよう | しよう | 来よう（こよう） |

---

## 1️⃣ ない形（否定形）

表示「不～、沒有～」。

### 變化規則

| 類型 | 規則 | 範例 |
|---|---|---|
| 五段動詞 | 最後音 → あ段 + ない | 書**く** → 書**か**ない |
| | | 読**む** → 読**ま**ない |
| | | 話**す** → 話**さ**ない |
| | 注意：う → わ | 買**う** → 買**わ**ない |
| | ある是例外 | ある → **ない**（不是あらない） |
| 一段動詞 | 去る + ない | 食べる → 食べない |
| 不規則 | 個別 | する → しない、来る → こない |

**例句**：
- <ruby>今日<rt>きょう</rt></ruby>は<ruby>学校<rt>がっこう</rt></ruby>に<ruby>行<rt>い</rt></ruby>か**ない** — 今天不去學校。
- <ruby>肉<rt>にく</rt></ruby>を<ruby>食<rt>た</rt></ruby>べ**ない** — 不吃肉。

---

## 2️⃣ て形（接續形）

最常用的活用形之一：連接句子、請求、進行式。

### 五段動詞的て形（依結尾變化）

| 結尾音 | て形 | 範例 |
|---|---|---|
| **く** | 〜いて | 書く → 書**いて** |
| **ぐ** | 〜いで | 泳ぐ → 泳**いで** |
| **う・つ・る** | 〜って | 買う → 買**って**、待つ → 待**って**、ある → あ**って** |
| **ぬ・ぶ・む** | 〜んで | 死ぬ → 死**んで**、遊ぶ → 遊**んで**、読む → 読**んで** |
| **す** | 〜して | 話す → 話**して** |

**口訣**：くいて、ぐいで、うつるって、ぬぶむんで、すして。

### て形的用途

| 用途 | 結構 | 範例 |
|---|---|---|
| 接續 | 〜て、〜 | <ruby>起<rt>お</rt></ruby>き**て**、<ruby>朝<rt>あさ</rt></ruby>ごはんを<ruby>食<rt>た</rt></ruby>べた — 起床後，吃了早餐 |
| 請求 | 〜てください | <ruby>待<rt>ま</rt></ruby>っ**て**ください — 請等一下 |
| 進行式 | 〜ている | <ruby>今<rt>いま</rt></ruby>、<ruby>食<rt>た</rt></ruby>べ**ている** — 正在吃 |
| 嘗試 | 〜てみる | <ruby>食<rt>た</rt></ruby>べ**て**みる — 吃吃看 |

---

## 3️⃣ た形（過去/完了形）

表示「做了～、已經～」。變化規則與て形完全對應：**把て換成た**。

| 結尾 | て形 | た形 |
|---|---|---|
| く | 書いて | 書いた |
| ぐ | 泳いで | 泳いだ |
| うつる | 買って | 買った |
| ぬぶむ | 読んで | 読んだ |
| す | 話して | 話した |

**例句**：
- <ruby>昨日<rt>きのう</rt></ruby>、<ruby>映画<rt>えいが</rt></ruby>を<ruby>見<rt>み</rt></ruby>**た** — 昨天看了電影。
- もう<ruby>食<rt>た</rt></ruby>べ**た** — 已經吃過了。

---

## 4️⃣ 受身形（被動態）

表示「被～、受到～」。

| 類型 | 規則 | 範例 |
|---|---|---|
| 五段動詞 | ない形 + れる | 書く → 書かない → 書か**れる** |
| 一段動詞 | 去る + られる | 食べる → 食べ**られる** |
| 不規則 | 個別 | する → **される**、来る → 来**られる** |

**例句**：
- <ruby>先生<rt>せんせい</rt></ruby>に<ruby>褒<rt>ほ</rt></ruby>め**られた** — 被老師稱讚了。
- <ruby>雨<rt>あめ</rt></ruby>に<ruby>降<rt>ふ</rt></ruby>**られた** — 被雨淋了。

---

## 5️⃣ 可能形

表示「能～、會～」。

| 類型 | 規則 | 範例 |
|---|---|---|
| 五段動詞 | 最後音 → え段 + る | 書く → 書**ける**、読む → 読**める** |
| 一段動詞 | 去る + られる | 食べる → 食べ**られる** |
| 不規則 | 個別 | する → **できる**、来る → 来**られる** |

> ⚠️ 一段動詞的可能形和受身形形式相同，靠語境判斷。

**例句**：
- <ruby>日本語<rt>にほんご</rt></ruby>が<ruby>話<rt>はな</rt></ruby>**せる** — 會說日文。
- <ruby>寿司<rt>すし</rt></ruby>が<ruby>食<rt>た</rt></ruby>べ**られる** — 能吃壽司。

---

## 6️⃣ 意向形（意志形）

表示「～吧、來～吧」。

| 類型 | 規則 | 範例 |
|---|---|---|
| 五段動詞 | 最後音 → お段 + う | 書く → 書**こう**、読む → 読**もう** |
| 一段動詞 | 去る + よう | 食べる → 食べ**よう** |
| 不規則 | 個別 | する → **しよう**、来る → 来**よう** |

**例句**：
- <ruby>一緒<rt>いっしょ</rt></ruby>に<ruby>行<rt>い</rt></ruby>**こう** — 一起去吧。
- <ruby>頑張<rt>がんば</rt></ruby>**ろう** — 加油吧。
