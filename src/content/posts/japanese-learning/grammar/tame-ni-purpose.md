# 〜ために

> 為了…

## 📖 基本形式

```
名詞 ＋ のために
例：家族のために / 未来のために

動詞辞書形 ＋ ために
例：合格するために / 夢を叶えるために
```

## 🎯 主要用法

1. **表示目的「為了…」**：說明做某件事是為了什麼。
2. 接**名詞**時用「名詞＋のために」；接**動詞**時用「動詞辞書形＋ために」。
3. 注意：動詞**た形**＋ために則表示「因為…」的原因用法（たために），意思不同，初學者先記住目的用法即可。
4. 口語中常省略成「〜ために」→「〜ため」。

## 🎵 歌曲應用

LiSA《炎》中「未来のために」出現兩次：

> <ruby>手<rt>て</rt></ruby>を<ruby>取<rt>と</rt></ruby>りそして<ruby>離<rt>はな</rt></ruby>した <ruby>未来<rt>みらい</rt></ruby>のために<br>
> <ruby>輝<rt>かがや</rt></ruby>いて<ruby>消<rt>き</rt></ruby>えてった <ruby>未来<rt>みらい</rt></ruby>のために

兩次「未来のために」都點出一個殘酷卻溫柔的抉擇：牽起手、然後放手；光芒閃耀、然後消逝——這一切都是「為了（守護）未來」。「ために」讓犧牲有了意義。
