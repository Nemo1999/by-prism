# を-賓格助詞

> 表示動作的直接對象的賓格助詞

## 📚 文法結構

### 基本形式
```
名詞 + を + 動詞
```

### 主要功能
1. **直接受詞**：表示動作的直接對象
2. **通過點**：表示移動通過的場所（如「橋を渡る」）
3. **起點**：表示離開的場所（如「家を出る」）

## 🎯 使用範例

### 直接受詞用法
**例句1**：<ruby>本を読む<rt>ほんをよむ</rt></ruby> — 讀書

**例句2**：<ruby>コーヒーを飲む<rt>コーヒーをのむ</rt></ruby> — 喝咖啡

### 歌曲應用
- **《Lemon》**：<ruby>あなたのことを夢に見る<rt>あなたのことをゆめにみる</rt></ruby> — 夢見你（「あなたのこと」為「夢に見る」的對象）

### 其他用法
**例句3**：<ruby>橋を渡る<rt>はしをわたる</rt></ruby> — 過橋（通過點）

**例句4**：<ruby>家を出る<rt>いえをでる</rt></ruby> — 離開家（起點）
