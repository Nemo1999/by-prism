# 〜の限り（かぎり）

> 竭盡…、以…為極限

## 📖 基本形式

```
名詞 ＋ の ＋ 限り（かぎり）
例：声の限り / 力の限り / 命の限り
```

## 🎯 主要用法

1. **表示「竭盡…」「以…為極限」**：把某個名詞當作極限，表示「把所有的…都用上」。
2. 常見搭配：**声の限り**（竭盡聲音）、**力の限り**（竭盡全力）、**命の限り**（竭盡生命）。
3. 文語色彩較濃，常出現在歌詞、文學作品或正式演說中；日常口語比較少用。

## 🎵 歌曲應用

LiSA《炎》的第一句：

> さよなら ありがとう <ruby>声<rt>こえ</rt></ruby>の<ruby>限<rt>かぎ</rt></ruby>り

「声の限り」＝竭盡聲音（所能呼喊）。歌詞表達的是：在離別之際，用盡全部力氣也要把「再見」和「謝謝」傳達出去。開頭就用如此強烈的方式，奠定了整首歌「盡全力傳達心意」的主題。
