# 夢に見る (ゆめにみる)

> 表示「夢見」的慣用表達

## 📚 文法結構

### 基本形式
```
名詞 + を + 夢に + 見る
```

### 文法解析
1. **夢**：名詞，作狀語修飾「見る」
2. **に**：格助詞，表示動作的目標或方向（在夢中）
3. **見る**：動詞，表示「看見」
4. **整體意義**：在夢中看見 → 夢見

### 相關形式
- **夢を見る**（ゆめをみる）：做夢（一般表達）
- **夢に現れる**（ゆめにあらわれる）：出現在夢中
- **夢に見る**（ゆめにみる）：夢見（強調在夢中看見的動作）

## 🎯 使用範例

### 基本用法
**例句1**：<ruby>昨夜、あなたを夢に見た<rt>さくや、あなたをゆめにみた</rt></ruby> — 昨晚我夢見了你。

**例句2**：<ruby>楽しいことを夢に見たい<rt>たのしいことをゆめにみたい</rt></ruby> — 我想夢到快樂的事情。

### 歌曲應用
**例句3**：<ruby>未だにあなたのことを夢に見る<rt>いまだにあなたのことをゆめにみる</rt></ruby> — 至今仍然夢見你（《Lemon》歌詞）。

**例句4**：<ruby>子供の頃の記憶を夢に見ることがある<rt>こどものころのきおくをゆめにみることがある</rt></ruby> — 有時會夢到童年的記憶。

### 變形用法
**例句5**：<ruby>彼が夢に出てきた<rt>かれがゆめにでてきた</rt></ruby> — 他出現在我的夢中。

**例句6**：<ruby>夢の中で会ったことがある<rt>ゆめのなかであったことがある</rt></ruby> — 曾經在夢中見過。
