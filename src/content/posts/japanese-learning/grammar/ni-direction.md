# に-方向助詞

> 表示方向、目標、地點的格助詞

## 📚 文法結構

### 基本形式
```
名詞 + に + 移動動詞
名詞 + に + 存在動詞
```

### 主要功能
1. **方向**：表示移動的方向或目標
2. **目標**：表示動作的目標對象
3. **地點**：表示存在的地點
4. **時間**：表示具體的時間點
5. **目的**：表示動作的目的

## 🎯 使用範例

### 方向用法
**例句1**：<ruby>学校に行きます<rt>がっこうにいきます</rt></ruby> — 去學校（方向）。

**例句2**：<ruby>東京に着きました<rt>とうきょうにつきました</rt></ruby> — 到達了東京（目標）。

### 目標用法
**例句3**：<ruby>友達に会います<rt>ともだちにあいます</rt></ruby> — 與朋友見面（對象）。

**例句4**：<ruby>先生に質問します<rt>せんせいにしつもんします</rt></ruby> — 向老師提問（目標）。

### 地點用法
**例句5**：<ruby>机の上に本があります<rt>つくえのうえにほんがあります</rt></ruby> — 桌子上有書（存在地點）。

**例句6**：<ruby>図書館にいます<rt>としょかんにいます</rt></ruby> — 在圖書館（存在地點）。

### 時間用法
**例句7**：<ruby>8時に起きます<rt>はちじにおきます</rt></ruby> — 8點起床（時間點）。

**例句8**：<ruby>月曜日に会議があります<rt>げつようびにかいぎがあります</rt></ruby> — 星期一有會議（時間）。

### 歌曲應用
- **《Lemon》**：<ruby>夢に見る<rt>ゆめにみる</rt></ruby> — 夢見（「に」表示在夢中這個「場所」進行「見る」的動作）。
