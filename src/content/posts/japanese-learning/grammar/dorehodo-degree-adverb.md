# どれほど-程度副詞

> 表示「多麼、何等」的程度疑問和感嘆

## 📚 文法結構

### 基本形式
```
どれほど + 形容詞/動詞
```

### 主要功能
1. **疑問**：詢問程度
2. **感嘆**：表達強烈的程度感嘆
3. **修飾**：強調形容詞或動詞的程度

## 🎯 使用範例

**例句1**：<ruby>あの景色はどれほど美しいでしょう<rt>あのけしきはどれほどうつくしいでしょう</rt></ruby> — 那景色是多麼美麗啊。

**例句2**：<ruby>彼の喜びはどれほど大きかったでしょう<rt>かれのよろこびはどれほどおおきかったでしょう</rt></ruby> — 他的喜悅是多麼大啊。

**例句3**：<ruby>この仕事がどれほど大切かわかりますか<rt>このしごとがどれほどたいせつかわかりますか</rt></ruby> — 你知道這工作有多重要嗎？

**例句4**：<ruby>あなたの優しさがどれほど私を助けたか<rt>あなたのやさしさがどれほどわたしをたすけたか</rt></ruby> — 你的溫柔給了我多大的幫助啊。

### 歌曲應用
- **《Lemon》**：<ruby>夢ならばどれほどよかったでしょう<rt>ゆめならばどれほどよかったでしょう</rt></ruby> — 如果是夢該有多好（表達強烈的願望感嘆）
