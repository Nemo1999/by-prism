# でしょう-推量感嘆

> 表示推量、確認、感嘆的助動詞

## 📚 文法結構

### 基本形式
```
形容詞/動詞辭書形 + でしょう
名詞/な形容詞 + でしょう
```

### 主要功能
1. **推量**：表達推測或不確定的判斷
2. **確認**：尋求對方同意或確認
3. **感嘆**：表達強烈的情感或感嘆

## 🎯 使用範例

### 推量用法
**例句1**：<ruby>明日は雨が降るでしょう<rt>あしたはあめがふるでしょう</rt></ruby> — 明天可能會下雨吧。

**例句2**：<ruby>彼はもう着いているでしょう<rt>かれはもうついているでしょう</rt></ruby> — 他可能已經到了吧。

### 確認用法
**例句3**：<ruby>この料理、美味しいでしょう<rt>このりょうり、おいしいでしょう</rt></ruby> — 這道菜很好吃吧（尋求同意）。

**例句4**：<ruby>彼女の笑顔、素敵でしょう<rt>かのじょのえがお、すてきでしょう</rt></ruby> — 她的笑容很迷人吧（尋求確認）。

### 感嘆用法
**例句5**：<ruby>あの景色はどれほど美しいでしょう<rt>あのけしきはどれほどうつくしいでしょう</rt></ruby> — 那景色是多麼美麗啊。

**例句6**：<ruby>夢ならばどれほどよかったでしょう<rt>ゆめならばどれほどよかったでしょう</rt></ruby> — 如果是夢該有多好（強烈願望感嘆）。

### 歌曲應用
- **《Lemon》**：<ruby>夢ならばどれほどよかったでしょう<rt>ゆめならばどれほどよかったでしょう</rt></ruby> — 使用「でしょう」表達強烈的願望感嘆
