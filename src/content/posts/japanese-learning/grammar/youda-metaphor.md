# ようだ-比喻表達

> 表示比喻、例示、推量的助動詞

## 📚 文法結構

### 基本形式
```
動詞辭書形/ない形 + ようだ
い形容詞 + ようだ
名詞 + の + ようだ
な形容詞 + な + ようだ
```

### 主要功能
1. **比喻**：表示「像...一樣」的比喻
2. **例示**：舉例說明「例如...」
3. **推量**：表示「似乎...」的推測
4. **方式**：表示動作的方式「以...的方式」

## 🎯 使用範例

### 比喻用法
**例句1**：<ruby>彼の心は氷のように冷たい<rt>かれのこころはこおりのようにつめたい</rt></ruby> — 他的心像冰一樣冷。

**例句2**：<ruby>鳥のように空を飛びたい<rt>とりのようにそらをとびたい</rt></ruby> — 想像鳥一樣在天空飛翔。

### 例示用法
**例句3**：<ruby>東京のような大都市<rt>とうきょうのようなだいとし</rt></ruby> — 像東京這樣的大都市。

**例句4**：<ruby>彼のような優しい人<rt>かれのようなやさしいひと</rt></ruby> — 像他那樣溫柔的人。

### 歌曲應用
- **《Lemon》**：<ruby>忘れた物を取りに帰るように<rt>わすれたものをとりにかえるように</rt></ruby> — 就像回去取忘記的東西一樣（比喻表達）
