# ようだ-比喻表達

> 表示比喻、例示、推量的助動詞

## 📚 文法結構

### 基本形式
```
動詞辭書形/ない形 + ようだ
い形容詞 + ようだ
名詞 + の + ようだ
な形容詞 + な + ようだ
```

### 主要功能
1. **比喻**：表示「像...一樣」的比喻
2. **例示**：舉例說明「例如...」
3. **推量**：表示「似乎...」的推測
4. **方式**：表示動作的方式「以...的方式」
