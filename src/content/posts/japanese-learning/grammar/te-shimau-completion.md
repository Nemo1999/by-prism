# 〜てしまう／〜てしまえば

> 完了（做完了）・遺憾（不小心…了）

## 📖 基本形式

```
動詞て形 ＋ しまう
動詞て形 ＋ しまえば（ば形條件：如果…了的話）
例：食べてしまう / 忘れてしまった / 眠ってしまえば
```

## 🎯 主要用法

1. **完了**：表示動作「徹底完成、結束」，例如「食べてしまった」＝吃完了。
2. **遺憾／後悔**：表示「不小心…了、無奈地…了」，例如「忘れてしまった」＝不小心忘了。
3. **〜てしまえば（ば形條件）**：把「〜てしまう」變成假設條件，意思是「如果…了的話」。
4. 口語中「〜てしまう」常縮約成「〜ちゃう」（食べちゃう、忘れちゃった）。

## 🎵 歌曲應用

LiSA《炎》：

> <ruby>悲<rt>かな</rt></ruby>しみに<ruby>飲<rt>の</rt></ruby>まれ<ruby>落<rt>お</rt></ruby>ちてしまえば<br>
> <ruby>痛<rt>いた</rt></ruby>みを<ruby>感<rt>かん</rt></ruby>じなくなるけれど

「悲しみに飲まれ落ちてしまえば」＝如果被悲傷吞噬而沉落的話。這裡的「〜てしまえば」是假設：如果徹底被悲傷吞沒（しまえば），就會感覺不到疼痛了——但歌詞緊接著用「けれど」轉折，表達「可是，我仍然選擇繼續感受這份痛、繼續守護」。
