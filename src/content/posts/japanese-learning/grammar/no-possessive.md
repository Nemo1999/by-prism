# の-所有格

> 表示所有、所屬、關聯的格助詞

## 📚 文法結構

### 基本形式
```
名詞A + の + 名詞B
```

### 主要功能
1. **所有**：表示名詞A擁有名詞B
2. **所屬**：表示名詞B屬於名詞A
3. **關聯**：表示兩個名詞之間的關聯性
4. **內容**：表示名詞B的內容或屬性

## 🎯 使用範例

### 所有關係
**例句1**：<ruby>私の本<rt>わたしのほん</rt></ruby> — 我的書

**例句2**：<ruby>先生の車<rt>せんせいのくるま</rt></ruby> — 老師的車

### 所屬關係
**例句3**：<ruby>学校の生徒<rt>がっこうのせいと</rt></ruby> — 學校的學生

**例句4**：<ruby>会社の社長<rt>かいしゃのしゃちょう</rt></ruby> — 公司的社長

### 關聯性
**例句5**：<ruby>日本語の文法<rt>にほんごのぶんぽう</rt></ruby> — 日語的文法

**例句6**：<ruby>昨日の会議<rt>きのうのかいぎ</rt></ruby> — 昨天的會議

### 歌曲應用
- **《Lemon》**：<ruby>あなたのこと<rt>あなたのこと</rt></ruby> — 你的事情（「あなた」與「こと」的關聯）
