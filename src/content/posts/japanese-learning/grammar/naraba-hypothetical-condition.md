# ならば-假設條件

> 表示「如果...的話」的假設條件

## 📚 文法結構

### 基本形式
```
名詞/な形容詞 + ならば + 句子
い形容詞/動詞辭書形 + ならば + 句子
```

### 主要功能
提出一個假設條件，說明在該條件下會發生的情況。
