# 〜ずに

> 不…而…

## 📖 基本形式

```
動詞ない形（去ない） ＋ ずに
例：食べる→食べずに / 言う→言わずに / 諦める→諦めずに
```

## 🎯 主要用法

1. **表示「不…而…」**：在沒有做某件事的狀態下，去做另一件事。
2. 變化方式：先做出**ない形**（否定形），再把「ない」換成「ずに」。
   - 書く → 書かない → **書かずに**（不寫而…）
   - 食べる → 食べない → **食べずに**（不吃而…）
   - する → しない → **せずに**（不做而…）
3. 「〜ないで」意思幾乎相同，但「〜ずに」文語色彩較濃，歌詞中很常見。

## 🎵 歌曲應用

LiSA《炎》的高潮：

> <ruby>振<rt>ふ</rt></ruby>り返<rt>かえ</rt>らずに<ruby>進<rt>すす</rt></ruby>むから

「振り返らずに進む」＝不回頭地前進。「振り返る」的ない形是「振り返らない」，去掉「ない」加上「ずに」就變成「振り返らずに」。歌詞表達的是：下定決心不再回頭、不再留戀，只顧向前邁進的強烈意志。
