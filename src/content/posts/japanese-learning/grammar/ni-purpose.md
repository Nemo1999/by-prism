# に-目的表達

> 表示動作的目的，使用「動詞連用形 + に + 動詞」結構

## 📚 文法結構

### 基本形式
```
動詞ます形（去ます） + に + 動詞
```

### 文法解析
1. **に**：格助詞，表示目的
2. **前接動詞**：動詞的ます形去掉「ます」，表示目的的動作
3. **後接動詞**：表示為了達成目的而進行的動作

## 🎯 使用範例

### 基本用法
**例句1**：<ruby>本<rt>ほん</rt></ruby>を<ruby>借<rt>か</rt></ruby>りに<ruby>図書館<rt>としょかん</rt></ruby>に<ruby>行<rt>い</rt></ruby>く — 去圖書館借書。

**例句2**：<ruby>食事<rt>しょくじ</rt></ruby>をしに<ruby>レストラン<rt>レストラン</rt></ruby>へ<ruby>行<rt>い</rt></ruby>った — 去餐廳吃飯。

### 歌曲應用
**例句3**：<ruby>忘れた物を取りに帰る<rt>わすれたものをとりにかえる</rt></ruby> — 回去取忘記的東西（《Lemon》歌詞）。

**例句4**：<ruby>友達に会いに行きます<rt>ともだちにあいにいきます</rt></ruby> — 去見朋友。

### 其他常見表達
**例句5**：<ruby>買い物に行く<rt>かいものにいく</rt></ruby> — 去購物。

**例句6**：<ruby>遊びに来てください<rt>あそびにきてください</rt></ruby> — 請來玩。

## 🔄 文法重點

### 接續規則
1. **一類動詞（五段動詞）**：ます形去掉「ます」
   - 行く → 行きます → 行きに
   - 飲む → 飲みます → 飲みに
2. **二類動詞（一段動詞）**：ます形去掉「ます」
   - 食べる → 食べます → 食べに
   - 見る → 見ます → 見に
3. **三類動詞（不規則動詞）**：
   - する → します → しに
   - 来る → きます → 来（き）に

### 注意事項
- 目的表達中的「に」不能與表示方向的「へ」互換，因為「に」強調目的，而「へ」強調方向。
- 目的表達通常用於移動動詞（行く、来る、帰る、戻る等）之前。
