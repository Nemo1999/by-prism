# よかった-願望表達

> 使用「よかった」表達「就好了」的願望或遺憾

## 📚 文法結構

### 基本形式
```
動詞て形 + よかった
い形容詞く形 + よかった
```

### 主要功能
1. **表達願望**：表達「如果...就好了」的願望
2. **表達遺憾**：表達對過去情況的遺憾或後悔
3. **表達慶幸**：表達「幸好...」的慶幸感

## 🎯 使用範例

### 願望表達
**例句1**：<ruby>夢ならばどれほどよかったでしょう<rt>ゆめならばどれほどよかったでしょう</rt></ruby> — 如果是夢該有多好（強烈願望）。

**例句2**：<ruby>もっと早く来ればよかった<rt>もっとはやくくればよかった</rt></ruby> — 要是早點來就好了。

### 遺憾表達
**例句3**：<ruby>あの時、行けばよかった<rt>あのとき、いけばよかった</rt></ruby> — 那時候去的話就好了（表達遺憾）。

**例句4**：<ruby>もっと勉強すればよかった<rt>もっとべんきょうすればよかった</rt></ruby> — 要是再多讀點書就好了。

### 慶幸表達
**例句5**：<ruby>傘を持ってきてよかった<rt>かさをもってきてよかった</rt></ruby> — 幸好帶了傘來。

**例句6**：<ruby>あなたに会えてよかった<rt>あなたにあえてよかった</rt></ruby> — 能遇見你真好。

### 歌曲應用
- **《Lemon》**：<ruby>夢ならばどれほどよかったでしょう<rt>ゆめならばどれほどよかったでしょう</rt></ruby> — 使用「よかった」表達強烈的願望感嘆
