# 〜たび（に）

> 每當…的時候

## 📖 基本形式

```
動詞辞書形 ＋ たび（に）
例：見るたびに / 会うたびに / 叶うたび
```

## 🎯 主要用法

1. **表示「每當…的時候」**：某件事每次發生時，都會伴隨另一件事。
2. 「たび」是名詞「度（たび）」的用法，前面接動詞辞書形（原形）。
3. 後面常搭配「〜する」「〜になる」「〜思い出す」等表示反覆動作或狀態變化的詞。
4. 語感上帶有「每一次都如此」的強調，比「〜とき」更有規律性。

## 🎵 歌曲應用

LiSA《炎》的副歌：

> <ruby>夢<rt>ゆめ</rt></ruby>が<ruby>一<rt>ひと</rt></ruby>つ<ruby>叶<rt>かな</rt></ruby>うたび <ruby>僕<rt>ぼく</rt></ruby>は<ruby>君<rt>きみ</rt></ruby>を<ruby>想<rt>おも</rt></ruby>うだろう

「夢が一つ叶うたび」＝每當一個夢想實現的時候。歌詞的悲傷之處在於：實現夢想的喜悅時刻，每次都會想起已經不在身邊的你——「たび」強調了這種思念會一次又一次地重複。
