# こと-形式名詞

> 表示抽象的事物、事情的形式名詞

## 📚 文法結構

### 基本形式
```
動詞/形容詞 + こと
名詞 + の + こと
```

### 主要功能
1. **抽象化**：將動作或狀態抽象化為事物
2. **強調對象**：與「の」連用，強調對象本身（〜のこと）
3. **名詞化**：使動詞或形容詞能夠充當名詞成分

## 🎯 使用範例

### 抽象化用法
**例句1**：<ruby>日本語を勉強することが好きです<rt>にほんごをべんきょうすることがすきです</rt></ruby> — 喜歡學習日語（將「學習日語」抽象化為一件事）。

**例句2**：<ruby>大切なことを忘れた<rt>たいせつなことをわすれた</rt></ruby> — 忘記了重要的事情。

### 強調對象（〜のこと）
**例句3**：<ruby>あなたのことを心配している<rt>あなたのことをしんぱいしている</rt></ruby> — 我很擔心你（強調「你」這個對象）。

**例句4**：<ruby>彼のことをよく知っている<rt>かれのことをよくしっている</rt></ruby> — 我很了解他（強調「他」這個對象）。

### 歌曲應用
- **《Lemon》**：<ruby>あなたのことを夢に見る<rt>あなたのことをゆめにみる</rt></ruby> — 夢見你（使用「こと」強調「你」這個對象）。
