# 〜ほど

> 越…越…（比例）

## 📖 基本形式

```
動詞辞書形 / い形容詞 / な形容詞 ＋ ほど
例：大人になるほど / 勉強するほど / 年を取るほど

強調形式：〜ば〜ほど（越…就越…）
例：練習すればするほど上手くなる
```

## 🎯 主要用法

1. **比例用法（越…越…）**：前項的程度越高，後項也跟著變化。是這次歌曲的重點。
2. **程度用法（〜ほど〜ない）**：表示「沒有比…更…」——「AほどBない」＝沒有比A更B的。
3. 口語中常聽到「〜ば〜ほど」的強調形式，例如「練習すればするほど上手くなる」。

## 🎵 歌曲應用

LiSA《炎》：

> <ruby>大人<rt>おとな</rt></ruby>になるほど<ruby>増<rt>ふ</rt></ruby>えて<ruby>行<rt>い</rt></ruby>く

「大人になるほど増えて行く」＝越是長大成人，就越是不斷增加。歌詞沒有直接說「增加的是什麼」，留給聽眾想像——可能是無法割捨的牽絆、不想失去的回憶，或是對重要之人的思念。「ほど」把「成長」和「增加」連結成比例關係，是這句的靈魂。
