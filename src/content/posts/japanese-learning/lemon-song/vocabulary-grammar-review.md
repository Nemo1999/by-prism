## 📚 文法重點總整理

### 1. 假設條件：「～ならば」
```markdown
**結構**：名詞 + ならば + 句子
**意思**：如果...的話
**例句**：学生ならば勉強する（如果是學生就要學習）
**練習**：雨ならば傘を持っていく（如果下雨就帶傘）
```

### 2. 感嘆表達：「どれほど～でしょう」
```markdown
**結構**：どれほど + 形容詞/動詞 + でしょう
**意思**：該有多麼...啊
**例句**：どれほど美しいでしょう（該有多美麗啊）
**練習**：どれほど嬉しいでしょう（該有多高興啊）
```

### 3. 目的表達：「～に＋動詞」
```markdown
**結構**：動詞ます形（去掉ます） + に + 移動動詞
**意思**：去（做某事）
**例句**：勉強しに行く（去學習）
**練習**：買い物に行く（去購物）
```

### 4. 比況比喻：「～ように」
```markdown
**結構**：動詞/形容詞 + ように
**意思**：像...一樣
**例句**：鳥のように飛ぶ（像鳥一樣飛）
**練習**：子供のように遊ぶ（像孩子一樣玩）
```

### 5. 過去修飾：「～た＋名詞」
```markdown
**結構**：動詞た形 + 名詞
**意思**：...了的（名詞）
**例句**：読んだ本（讀過的書）
**練習**：食べたご飯（吃過的飯）
```

### 6. 否定方式：「～ずに」
```markdown
**結構**：動詞未然形 + ずに
**意思**：不...地（做某事）
**例句**：食べずに寝る（不吃就睡）
**練習**：言わずに去る（不說就離開）
```

### 7. 狀態持續：「～まま」
```markdown
**結構**：動詞た形/形容詞 + まま
**意思**：保持...的狀態
**例句**：窓を開けたまま（保持窗戶開著）
**練習**：そのまま待つ（保持那樣等待）
```

### 8. 可能形：「～ことができる」
```markdown
**結構**：動詞辭書形 + ことができる
**意思**：能夠（做某事）
**例句**：日本語を話すことができる（能夠說日文）
**練習**：泳ぐことができる（能夠游泳）
```

### 9. 授受表現：「～てくれる」
```markdown
**結構**：動詞て形 + くれる
**意思**：（別人）為我做...
**例句**：教えてくれる（教我）
**練習**：手伝ってくれる（幫助我）
```

### 10. 條件形：「～なきゃ」
```markdown
**結構**：動詞未然形 + なきゃ
**意思**：如果不...的話（口語）
**例句**：行かなきゃ（如果不去的話）
**練習**：食べなきゃ（如果不吃的話）
```
